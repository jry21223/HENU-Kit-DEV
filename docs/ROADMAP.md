# Roadmap

## 当前阶段

Phase 15：移动端优化（基础版完成）。

当前状态：

- Phase 0 到 Phase 15 已完成基础验收。
- 当前已具备 Next.js + TypeScript + Tailwind + Prisma + PostgreSQL MVP。
- 已实现资料平台、学生邮箱登录、下载权限、admin 基础写 API、在线题库、错题本、课程复习包、支付基础版、资料共建审核、AI 草稿任务、PDF 动态水印和运营统计基础版。
- 后续进入按真实运营需求细化的迭代阶段。

## Phase 0：仓库审查与项目初始化

目标：

- 审查仓库结构。
- 判断技术栈和可复用模块。
- 输出项目现状报告。
- 建立长期开发文档。
- 给出 Phase 1 文件级 TODO。

验收：

- 能清楚说明当前仓库结构。
- 能说明采用什么技术栈。
- 能说明第一批代码改动怎么做。
- 不产生破坏性业务代码改动。

## Phase 1：MVP 信息架构与静态页面

目标：

- 创建可运行的 Next.js 项目。
- 做出首页、登录页、学校选择、课程列表、课程详情、资料详情、管理后台首页。
- 使用 mock 数据展示河南大学软件学院课程和资料。

验收：

- 核心页面能访问。
- 移动端不崩。
- UI 简洁、教育工具感。
- 不接数据库、不接真实登录、不接支付、不接 AI。

## Phase 2：数据库与基础数据模型

目标：

- 引入 PostgreSQL 和 Prisma。
- 建立 users、schools、colleges、majors、courses、materials、downloads、email_verifications。
- 预留 questions、wrong_questions、orders、entitlements。
- seed 河南大学软件学院示例数据。

验收：

- 数据库迁移成功。
- seed 数据插入成功。
- 页面能从数据库读取课程和资料。

## Phase 3：学生邮箱登录

目标：

- 实现邮箱验证码登录。
- 校验 `henu.edu.cn` 和 `stu.henu.edu.cn`。
- 开发环境服务端输出验证码。
- 登录后绑定 school、major、grade。

验收：

- 合法学生邮箱可以登录。
- 非白名单邮箱不能登录。
- 验证码过期和一次性使用有效。
- 登录、当前用户、退出流程可用。

## Phase 4：课程与资料真实数据流

目标：

- 首页、课程列表、课程详情、资料详情全部读取数据库。
- API 支持学校、学院、专业、课程、资料查询。

验收：

- 不同专业可看到不同课程。
- 普通用户只能看到 published 资料。
- 空状态和不存在状态有清楚提示。

## Phase 5：资料下载权限控制

目标：

- 实现 free、login_required、paid 三类访问等级。
- 下载 API 记录 downloads。
- paid 内容暂不接支付，只显示需要解锁。

验收：

- free 未登录可下载。
- login_required 必须登录且邮箱验证。
- paid 不能绕过。
- 下载有记录。

## Phase 6：管理员后台

目标：

- 管理课程和资料。
- 支持上传资料、编辑资料、状态流转。
- admin 权限在服务端检查。

验收：

- admin 能新增、编辑、发布课程和资料。
- 普通学生不能访问后台。
- 未发布资料不出现在前台。

## Phase 7：在线题库基础版

目标：

- 支持单选题和判断题。
- 按课程刷题。
- 提交答案后显示对错和解析。
- 登录用户错题自动保存。

验收：

- 未登录可试做但不保存错题。
- 题目列表不暴露答案。
- 错题不重复记录。

当前状态：

- 已完成基础验收。
- 结果页暂使用浏览器本地结果，不新增练习 session 表。
- 完整错题本体验留到 Phase 8。

## Phase 8：错题本与知识点关联

目标：

- 我的错题、课程筛选、知识点筛选、移除错题、重新练习。
- 展示薄弱知识点统计。

验收：

- 用户只能看到自己的错题。
- 删除错题不影响题库。
- 知识点为空时页面正常。

当前状态：

- 已完成基础验收。
- 重新练习入口当前回到课程练习页，错题专项 session 留到后续。

## Phase 9：课程复习包与权限体系

目标：

- 支持 course package、package items、entitlements。
- 后台手动授权。
- 前台展示 locked / unlocked。

验收：

- 未授权用户不能访问 paid 内容。
- 已授权用户可以访问 paid 内容。
- 支持过期时间。

当前状态：

- 已完成基础验收。
- 支付前通过 admin API 手动授权。
- entitlement 撤销和授权列表留到后续后台细化。

## Phase 10：支付接入

目标：

- 接入易支付优先。
- 创建订单、支付回调、签名校验、发放 entitlement。

验收：

- 支付成功后自动授权。
- 重复回调不重复授权。
- 金额、签名、用户绑定校验正确。

当前状态：

- 已完成基础验收。
- 当前实现为易支付兼容协议，支持本地签名和回调闭环。
- 未绑定真实商户号和真实支付网关；上线前必须按具体服务商文档复核。
- 未实现退款、取消、支付查询和后台订单管理。

## Phase 11：资料共建与审核

目标：

- 学生投稿。
- reviewer/admin 审核。
- 审核通过后生成 material。

验收：

- 投稿不会直接发布。
- 驳回有原因。
- 审核记录可追溯。

当前状态：

- 已完成基础验收。
- 学生投稿支持 PDF/TXT 和 10MB 限制，保存到 `uploads/submissions`。
- reviewer/admin 可查看投稿并通过或驳回。
- 审核通过后生成 `material`，审核前不会前台展示。
- 投稿归档、投稿文件下载权限细化、贡献者角色升级留到后续。

## Phase 12：AI 辅助内容生成

目标：

- 管理员创建 AI 生成任务。
- 生成知识点、讲义、模拟卷、答案解析草稿。
- AI 结果必须人工审核。

验收：

- AI 内容不会自动发布。
- 失败有错误信息。
- 生成结果绑定来源资料。

当前状态：

- 已完成基础验收。
- 当前为本地 deterministic 草稿生成，不接真实 AI。
- admin 可创建 succeeded 或 failed AI job。
- succeeded job 会创建 draft material，前台不可见。
- failed job 保存 error。
- 真实模型调用、文本提取、公式处理和重试机制留到后续。

## Phase 13：PDF 水印与防盗传

目标：

- PDF 下载动态加水印。
- 水印包含用户、时间、用途声明。
- 原文件不被破坏。

验收：

- 每页都有浅灰斜向水印。
- 中文不乱码。
- 非 PDF 文件正常处理或明确提示。

当前状态：

- 已完成基础验收。
- PDF 下载时在内存中生成水印副本，不覆盖原文件。
- 水印包含用途声明、用户邮箱或未登录标识、下载时间。
- 非 PDF 文件保留原下载逻辑，并返回 `X-Watermark-Applied: false`。
- 大文件性能优化和对象存储临时文件留到后续。

## Phase 14：数据统计与运营后台

目标：

- 管理员查看用户、课程访问、资料下载、练习、错题知识点分布等指标。

验收：

- 热门课程、高下载资料、高错题知识点可见。
- 不泄露用户隐私。

当前状态：

- 已完成基础验收。
- admin 可查看核心计数、热门课程、高下载资料和高错题知识点。
- API 不返回用户邮箱明细。
- 尚未建立课程访问日志，热门课程当前以课程相关下载量近似。
- 下载与错题聚合当前最多读取最近 1000 条记录，后续可改为离线聚合。

## Phase 15：移动端优化

目标：

- 优化首页、课程列表、课程详情、资料详情、刷题、错题本、登录页移动端体验。

验收：

- iPhone 视口可正常浏览。
- 无横向滚动。
- 按钮足够大。
- 刷题阅读舒适。

当前状态：

- 已完成基础验收。
- Browser 390px 巡检首页、登录、学校、课程、课程详情、资料详情、刷题、结果、错题本、投稿、订单和统计页均无横向溢出。
- 筛选控件高度提升到 44px。
- 刷题单选控件增大，选项整行可点击。
- 首页、学校页、404 和 admin 首页过期阶段文案已清理。
