# QuizCraft 在无人使用维护期执行全量切换

QuizCraft 在期末结束后处于无人使用维护期，因此生产迁移不再要求比例读灰度，而是在短暂技术停写窗口内完成最终增量同步、双库可恢复快照和数据对账后，一次性将 100% 读写流量切换到 Go。无人使用不代表零写入，所以技术停写和可验证回退点仍是强制门禁。

Go 接受首笔持久化写入后，不得直接将流量切回旧库；故障时重新进入维护状态并前向修复。只有将切换后的 Go 写入完整反向同步到旧库且对账通过，才能恢复旧服务写入。

Platform Core 必须先以独立服务部署在 `account.superhuazai.me`，完成真实邮箱发送、邮箱身份、15 天绝对 Core Session、OAuth 客户端与最小权限首位操作员验证。旧 QuizCraft 不自动映射到邮箱身份，历史排行只读保留。

比例分桶、浏览器 cohort、在线影子流量和旧服务在线观察不再是验收门禁；离线对比工具保留。切换后 FastAPI 停止并脱离 Nginx，以数据库只读的冷备形式保留 7 天；经人工批准后移除服务，最终双库备份及 SHA-256 记录保留 30 天。
