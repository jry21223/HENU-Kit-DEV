# 前端首页产品愿景设计

日期：2026-06-22

## 背景

本设计用于 `apps/web` 新首页。首页面向学生、创作者和普通访客，用来表达一站式学习平台 V2 的产品愿景。

项目当前核心定位来自 README 和 `CONTEXT.md`：

- Web 主站围绕课程资料、在线刷题、AI 辅助、Wiki 共创、社区讨论、积分会员和前台销售建立学习闭环。
- 第一阶段重点服务软件学院相关课程。
- 首页应以“课程资料库”和“资料库原生体验”为主线。
- AI、社区、积分会员和销售入口是围绕课程资料的扩展能力，不应抢占课程资料主入口。

参考页面是 SuperrBook 首页。可借鉴的是物件感、大留白、纸张质感、滚动叙事、书本随滚动摆正并翻开的体验。不可直接照搬儿童化贴纸风、低龄语气或与本项目无关的硬件产品表达。

## 设计目标

1. 让用户第一眼记住“软件学院资料库”这个产品物件，而不是看到普通资料下载站。
2. 用滚动打开资料册的方式，把“课程资料库”自然展开成课程入口和资料目录。
3. 在资料主线之后展示完整产品愿景：课程社区、刷题练习、AI 强化、积分会员、LangBot 咨询、资料保障。
4. 保持干净、可信、轻微学院感，同时允许课程小书和便签区更活泼多彩。
5. 桌面端提供完整 scroll-driven 体验，移动端保留核心视觉但降低动画复杂度。

## 非目标

- 不把首页做成全屏 AI 聊天入口。
- 不把首页做成纯营销页或活动页。
- 不承诺“必考命中”“老师原版”“全覆盖”等无法验证的能力。
- 不把课程社区做成泛社交或朋友圈。
- 不在移动端强行实现完整翻页动画。

## 页面叙事

### 1. 首屏：打开你的期末复习资料册

首屏采用大留白。左侧是短标题、简短说明、搜索入口和主要 CTA。右下角是一册斜放进入画面的“软件学院资料库”档案册。

建议文案方向：

- 标题：打开你的期末复习资料册
- 说明：按课程找到讲义、真题、实验资料和复习包，围绕资料继续刷题、讨论和共创。
- 主 CTA：进入课程资料
- 次 CTA：查看资料保障

档案册封面需要有明确产品名，例如“软件学院资料库”或“课程资料档案册”。封面可使用活泼色块和纸张质感，但整体背景保持干净。

### 2. 滚动翻开：资料目录 + 课程 PDF 小书

桌面端滚动分三段：

1. 资料册从右下角斜放状态摆正，并放大到页面中心。
2. 封面翻开，形成左右双页。
3. 左页目录逐项浮现，右页课程 PDF 小书依次落位。

打开后双页内容：

左页是“资料目录”，像纸质目录或索引页：

- 课程资料
- 历年真题
- 实验资料
- 复习笔记
- 课程包
- 刷题练习
- 我的下载

右页是“课程入口”，用几本不同颜色的 2D 偏 3D PDF 小图书表示课程。每本小书有封面、书脊、页边、轻微厚度、阴影和课程名。小书要像资料册封面，不像普通网页卡片。

推荐课程示例：

- 数据结构
- 操作系统
- 计算机网络
- 软件工程
- 数据库系统
- 编译原理

色彩方向：活泼多彩。可使用亮蓝、橙黄、草绿、玫红、紫色、青色。需要控制饱和度和阴影，避免变成儿童玩具感。

### 3. 便签墙：社区与共创

翻书段之后进入便签墙，参考 SuperrBook 的便签区。该区域用错落摆放的彩色便签介绍围绕课程的社区和共创能力。

建议四张便签：

- Wiki 共创：一起整理知识点、资料说明和课程复习脉络。
- 博客经验：沉淀复习路线、考前经验和避坑提醒。
- 课程帖子：围绕资料补充、勘误、提问和讨论展开。
- 学习动态：记录资料更新、贡献和课程相关活动。

该区域表达“资料不是一次性下载，而是围绕课程持续沉淀经验”。文案应避免泛社交口吻。

### 4. 练习纸：刷题与 AI 强化

下一段用练习纸、批改纸或错题卡视觉介绍练习能力：

- 在线刷题
- 错题本
- 薄弱点统计
- AI 针对性强化

AI 表达为课程和资料旁边的辅助能力，不作为首页主入口。文案应强调“针对错题和薄弱点辅助复习”，避免过度 AI 感。

### 5. 积分贴纸 / 会员票据：激励和权益

用贴纸、印章、票据或课程包票券视觉介绍积分会员体系：

- 创作者通过资料补充、内容贡献获得积分。
- 积分和会员用于权益控制。
- 课程包承接 paid 资料解锁。
- AI 使用成本通过积分或会员额度控制。

这是产品愿景表达，可以展示完整闭环。但在实现文案中应避免暗示真实微信支付已经上线，因为 README 明确真实商户联调尚未完成。

### 6. 咨询小纸条：LangBot 前台销售

LangBot 不是学生主流程，应作为辅助咨询入口出现。视觉上可以是底部或侧边贴纸、小纸条、问答便签。

表达能力：

- QQ/微信群咨询
- 套餐介绍
- 注册和购买引导
- 售后分流

该区域要轻，不应变成主 CTA 或大面积营销模块。

### 7. 资料保障：信任收束

页面末段用更稳定的视觉语言讲资料保障：

- 资料稳定供应
- 轻水印
- 持续维护
- 服务端权限校验
- 下载审计
- AI 草稿审核

这一段的视觉应比前面的便签和小书更克制，用来收束信任。文案避免夸大承诺，遵守 `CONTEXT.md` 中“资料保障承诺”的边界。

### 8. 最近更新 / 进入课程库

最后提供可行动入口：

- 最近更新资料
- 热门课程
- 进入课程库
- 登录后查看我的下载

如果实现阶段接入真实 API 有成本，可以先使用现有课程接口或静态示例数据，但设计上要能自然承接真实数据。

## 交互设计

### 桌面端

桌面端实现完整 scroll-driven 档案册体验：

- 首屏资料册斜放在右下区域。
- 滚动时资料册旋转、缩放、平移到中心。
- 继续滚动时封面翻开。
- 双页内容在翻开后出现。
- 左页目录按顺序淡入。
- 右页课程 PDF 小书带轻微下落或浮入效果。
- 后续便签、练习纸、票据区域随滚动轻微浮入和归位。

动画必须有 reduced-motion 降级。对于减少动态偏好的用户，直接展示已打开的资料册和静态内容。

### 移动端

移动端只保留核心识别，不做完整翻页：

- 顶部资料册从轻微倾斜到摆正。
- 课程 PDF 小书横向滚动或分组浮出。
- 目录改成紧凑分组按钮。
- 便签、练习纸、票据区改为单列布局。

移动端优先保证可读性和点击目标，不追求桌面同款动画。

## 视觉语言

整体基调：

- 干净
- 可信
- 轻微学院感
- 纸张和资料册质感
- 局部活泼多彩

可使用的视觉元素：

- 档案册
- PDF 小图书
- 便签
- 练习纸
- 批改痕迹
- 课程标签页
- 积分贴纸
- 会员票据
- 咨询小纸条

需要避免：

- 大面积儿童贴纸风
- 过度 AI 感
- 深色科技感
- 泛社交信息流感
- 三等分普通功能卡片堆叠
- 纯 dashboard 首页

## 内容边界

首页按产品愿景展示完整能力，但需要保持措辞谨慎：

- 可以展示 Wiki、博客、帖子、动态、积分会员、AI 强化、LangBot 销售等愿景能力。
- 不应写成所有能力已经完整上线。
- 支付相关文案不要暗示真实微信支付已经联调完成。
- AI 内容必须保留 draft/review 边界，不写自动发布。
- paid 资料下载必须强调服务端权限校验，不能表现为前端按钮隐藏即可解锁。

## 信息架构

推荐首页结构：

1. Hero：打开你的期末复习资料册
2. Scroll Reveal：资料册摆正并翻开
3. Open Book：资料目录 + 彩色课程 PDF 小书
4. Sticky Notes：Wiki、博客、帖子、动态
5. Practice Papers：刷题、错题本、薄弱点、AI 强化
6. Tickets / Stickers：积分、会员、课程包、AI 成本控制
7. Sales Note：LangBot 咨询和购买引导
8. Guarantee：资料保障和安全边界
9. Final CTA：进入课程资料库

## 组件边界建议

实现时应将复杂动画和静态内容分开：

- `HomePage`：页面组合和数据准备。
- `HeroIntro`：首屏标题、搜索和 CTA。
- `ArchiveBookReveal`：桌面端资料册摆正和翻开动画。
- `MobileArchiveIntro`：移动端简化资料册展示。
- `CourseBookGrid`：课程 PDF 小图书。
- `CommunityStickyNotes`：社群便签区。
- `PracticeVisionSection`：刷题与 AI 强化。
- `MembershipTicketSection`：积分会员和课程包。
- `SalesAssistantNote`：LangBot 咨询入口。
- `GuaranteeSection`：资料保障收束。

动画组件需要成为独立客户端组件。静态内容尽量保持服务器组件或普通渲染，减少全页客户端化。

## 验收标准

- 首屏能在不滚动时明确表达“软件学院资料库”。
- 桌面端滚动能看出资料册从斜放到摆正再翻开的连续过程。
- 打开后的左页是资料目录，右页是多彩课程 PDF 小图书。
- 便签区能清楚表达 Wiki、博客、帖子、动态。
- 后续区块覆盖刷题、错题本、薄弱点统计、AI 强化、积分会员、课程包、LangBot 和资料保障。
- 移动端没有复杂翻页，但仍有资料册和课程小书的核心识别。
- reduced-motion 下页面可正常阅读。
- 文案不夸大资料保障、AI、支付和社区能力。
- 首页视觉不是普通 dashboard，也不是低龄儿童产品。
