# 学生端首页莫兰迪资料库工作台设计

## 范围

本次只改 `apps/web` 学生端首页 `/`。管理端暂不处理，后续单独选择或接入管理端套件。

## 设计读法

这是面向本校软件学院学生的课程 PDF 资料库首页，不是营销 landing，也不是刷题首页。第一屏应直接呈现课程资料、最近更新和资料保障状态，让用户马上能按课程进入 PDF 资料。

## 已确认方向

- 首页采用 `sidebar-01` 风格的资料库 shell，而不是全屏大 Hero。
- 视觉改为浅色莫兰迪资料馆，不再使用紫色主色。
- 当前首页固定浅色纸面方向，不随系统暗色切回黑底。
- 管理端暂不改，后续直接上管理套件。
- 当前项目保持 Tailwind 3 兼容，不直接套用 Tailwind 4 preset 或 shadcn 最新区块代码。

## 首页结构

桌面端：

- 左侧固定资料库导航：品牌、Repository 分类、核心课程、资料补充建议、维护状态。
- 顶部内容栏：全局搜索、Repository / Courses / Resources 导航、通知和登录入口。
- 主内容区：breadcrumb、Today's Materials、状态面板、Core Modules、Document Repository 表格。
- 底部三块说明：资料保障、按课程组织、社区功能预留。

移动端：

- 顶部 sticky 品牌栏和搜索框。
- 横向滚动分类入口。
- 内容卡片按单列堆叠，文档表格切换为紧凑列表。

## 视觉规则

- 背景：暖灰纸面 + 细网格 + 中心柔光。
- 主色：灰绿只用于 active nav、主按钮、hover 和重点状态。
- 圆角：按钮和输入 4px 到 8px，主面板 12px。
- 阴影：使用极轻的暖灰浮层阴影，避免 dashboard 式硬边框。
- 文案：直接围绕课程、PDF、归档、水印、稳定供应，不写营销句。

## 数据策略

第一版首页使用静态展示数据和现有路由链接，不新增后端接口。若后续需要真实聚合数据，应记录为 API contract 需求，不在本次擅自改后端。

## 验收

- 第一屏不再出现大面积空白。
- 用户能立刻看到课程入口、PDF 条目、最近更新和保障状态。
- 首页视觉接近浅色学术资料馆和参考图的纸面网格工作台，而不是黑紫 dashboard。
- `/courses`、`/login` 等现有路由不受影响。
- `npm run lint` 和 `npm test` 通过。
