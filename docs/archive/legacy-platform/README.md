# 旧学习平台文档归档

本目录保存 `final-review-platform` 在 HENUKitDev Monorepo Foundation 之前形成的 V2 文档。

这些文件描述的是旧学习平台的混合业务边界、API、权限、积分会员、AI Mock、管理后台、数据库和阶段路线图。`superpowers/` 保存当时的 Study UI 设计与执行记录。它们用于追溯历史实现与迁移依据，不是 HENUKitDev 新功能的默认实现规范。

## 归档内容

- `context.md`：旧 Final Review Platform 的产品用语与承诺边界。
- `api.md`、`architecture.md`、`development.md`、`database.md`：旧 Study V2 技术说明。
- `admin-guide.md`：旧 Vue Admin 的页面和接口说明。
- `ai-workflow.md`、`points-membership.md`、`security.md`、`roadmap.md`：旧业务与安全说明。
- `superpowers/`：2026 年 6 月形成的旧 Study UI 规格和实施计划。
