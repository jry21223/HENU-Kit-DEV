## 产品入口与已知边界

- [HENU Kit 主站](https://henukit.cn/) 与 [Console](https://console.henukit.cn/) 分工独立。Console 是运营入口，管理行为仍由服务端角色与作用域授权；会员权益不授予管理权限。
- 2026-11-07 18:28 的已登录 Console 核查可访问平台、美食、工单及既有会员/积分入口。未以真实用户的权益、积分或通知写入作为验收手段。
- 同次核查中，通知管理接线未配置；不由此判断通知产品整体停服。
- 公开资料目录与资料管理是不同能力。公开目录可访问，旧资料管理能力尚未就绪；没有重新启用退役管理适配器。
- 摘要的“四项停用、两项未接入”保持原有配置。这是摘要接线状态，不等同于六个产品的可用性。
