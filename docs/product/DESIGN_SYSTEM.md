# HENU Kit Design System

> 状态：Baseline v1.1  
> 适用范围：主站、资料库、QuizCraft、校园生活模块及相关公开页面  
> 本文描述 HENU Kit 自有视觉系统，不代表河南大学官方视觉识别规范。

新增页面和功能必须遵守本基线。确需偏离时，应在 Issue 或 PR 中说明原因、影响范围、替代方案和清理期限。

## 1. 品牌定位

HENU Kit 是面向河南大学学生的统一校园工具系统，由学生自主发起、运营和维护。

正式介绍、首页、页脚、README、登录、支付和对外宣传中必须明确：

> HENU Kit 是由河南大学学生自主发起并维护的校园工具项目，非河南大学官方产品，不代表学校官方立场。

空间有限时使用：

> 学生自主运营 · 非河南大学官方项目

禁止：

- “河南大学官方工具箱”
- “河大官方平台”
- “学校指定平台”
- “河南大学官方标准色”
- 未经证实的官方认证、授权或合作表述

## 2. 品牌原则

### 学生视角

使用“找资料”“去刷题”“今天吃什么”等任务语言，避免行政系统式命名。

### 清楚直接

页面先说明用户能做什么。主操作优先于装饰和口号。

### 有校园感，但不冒充官方

可以使用纸张、书本、档案和学生共建的视觉隐喻；不得复制或改造河南大学校徽，不使用印章式构图暗示官方身份。

### 一个系统，多种工具

子产品可独立部署，但共享品牌入口、导航、账户位置、颜色、排版、按钮、卡片、状态和页脚声明。

### 功能克制

- 主站负责发现、进入、状态和继续任务，不复制业务正文。
- 资料库不开发第二套刷题。
- QuizCraft 不承担资料归档和综合门户。
- 新功能先说明真实用户任务、唯一 Owner 和验证方式。

## 3. 色彩

### Kit 墨绿

| Token | 色值 | 用途 |
|---|---:|---|
| `--hk-ink-green` | `#0C6B45` | 主按钮、品牌标志、重点标题、选中状态 |
| `--hk-ink-green-deep` | `#05603A` | Hover、按下、深色强调区 |
| `--hk-ink-green-soft` | `#E4EFE9` | 浅标签、成功提示、选中背景 |

“Kit 墨绿”是 HENU Kit 内部品牌命名，不是“河大绿”或河南大学官方标准色。

### 基础色

| Token | 色值 | 用途 |
|---|---:|---|
| `--hk-paper` | `#F5F1E7` | 页面主背景，称为纸白 |
| `--hk-paper-raised` | `#FFFFFF` | 卡片、弹层、输入区域 |
| `--hk-paper-line` | `#E9E6DB` | 分割线、边框、禁用背景 |
| `--hk-ink` | `#343D36` | 正文与主要文字 |
| `--hk-ink-muted` | `#6F766F` | 次要说明和元信息 |

### Kit 麦金

| Token | 色值 | 用途 |
|---|---:|---|
| `--hk-wheat-gold` | `#F0BE44` | 插画、徽标、少量重点提示 |
| `--hk-wheat-gold-soft` | `#F8E8B4` | 提示背景和轻装饰 |

麦金不作为大段正文颜色，不与白字组合成主要按钮。

### 使用比例

- 纸白与白色约 70%。
- 墨绿与文字色约 20%。
- 麦金和其他强调色不超过 10%。
- 每页只使用一个主要强调色。
- 美食、学习和工具模块不得发展彼此无关的主题色系统。

## 4. 排版

推荐字体：

```css
font-family: Inter, "Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif;
```

| 层级 | 桌面端 | 移动端 | 用途 |
|---|---:|---:|---|
| Display | 64–80px | 40–48px | 首页核心标题，仅一处 |
| H1 | 40–48px | 32–36px | 页面标题 |
| H2 | 28–32px | 24–28px | 区块标题 |
| H3 | 20–24px | 18–20px | 卡片标题 |
| Body | 16–18px | 16px | 正文 |
| Meta | 13–14px | 13–14px | 标签和辅助信息 |

操作页降低标题张力，优先扫描效率。正文行宽建议不超过 72 个中文字符。

## 5. 间距与形状

- 基础单位：4px。
- 常用间距：8 / 12 / 16 / 24 / 32 / 48 / 64px。
- 卡片圆角：12px。
- 大型展示卡片：20px。
- 胶囊只用于短标签和少量动作。
- 阴影克制，优先边框、留白和背景层级。

## 6. 全局产品外壳

所有学生端产品共享：

- HENU Kit 品牌入口。
- 一致的主导航顺序。
- 一致的登录/个人入口位置。
- 移动端底部导航规则。
- 统一非官方声明。
- 统一产品状态和错误语义。

模块名称以“HENU Kit · 学习”“HENU Kit · 校园生活”等方式出现，不建立与 HENU Kit 竞争的主品牌。

## 7. 导航

桌面端一级导航不超过 5 项，移动端底部导航不超过 5 项。

推荐：

```text
首页 / 找资料 / 去刷题 / 校园生活 / 我的
```

- Logo 返回 `henukit.cn`。
- 资料库与刷题是独立任务入口。
- 资料库“去刷题”进入 QuizCraft，并携带允许的课程上下文。
- 系统内产品默认当前标签页打开。
- 外部项目显示外部标识、维护者和风险说明，可新标签页打开。

## 8. 按钮

- Primary：Kit 墨绿背景、白字。
- Secondary：纸白或透明背景、墨色文字、浅边框。
- Tertiary：纯文字。
- Danger：只用于删除、退出和不可逆操作。

同一视区原则上只有一个 Primary 动作。按钮文案使用动词，例如“查看资料”“开始刷题”“发送验证码”，避免“确定”。

## 9. 卡片

卡片必须承载明确任务，不做纯装饰容器。课程、工具和美食卡片共享圆角、边框、标题和元信息层级，仅内容结构不同。

## 10. 状态

所有产品必须覆盖：

- Loading
- Empty
- Error
- Success
- Disabled
- Login required
- Permission denied
- Offline/maintenance（适用时）

错误信息说明发生了什么和下一步。空状态提供可执行动作，不用段子替代说明。

## 11. 表单

- 输入框必须有可见标签，placeholder 不能代替标签。
- 错误靠近字段，不只用颜色表达。
- 失败后保留非敏感输入。
- 验证码支持粘贴、自动聚焦和手动修改。
- 触控区域至少 44 × 44px。
- 键盘可完成登录、搜索、筛选和提交。

## 12. 资料库“打开资料册”

保留书本/资料册创意，但作为一次性轻量进入动画：

- `600–900ms`。
- 核心层 `3–6` 个。
- 只使用 `transform` 与 `opacity`。
- 标题、搜索和主要按钮首帧可见可操作。
- 桌面端允许轻微 Hover。
- 移动端默认静态或简单淡入。
- `prefers-reduced-motion: reduce` 关闭非必要动画。
- 禁止长距离 sticky、连续翻页、多层视差和滚动期间持续位置计算进入关键路径。

完整版动效可保留为宣传录屏或设计存档，不进入用户找资料的默认流程。

## 13. 响应式与可访问性

- 移动优先，360px 宽度核心流程可用。
- 正文不小于 16px。
- 点击区域不小于 44 × 44px。
- 正文与背景至少 WCAG AA。
- 焦点状态不得移除。
- 图片有有意义的 alt，装饰图使用空 alt。
- 动画短而克制，尊重减少动态设置。
- 不依赖 Hover 完成核心任务。

## 14. 统一账户和隐私界面

- 账户入口使用 `account.henukit.cn`。
- 学生邮箱验证码只证明邮箱控制权，不描述为学校认证。
- 发件域使用 `notify.henukit.cn`，发件人不得暗示官方身份。
- 验证码 5–10 分钟过期、单次使用，至少 60 秒重发等待。
- 完整邮箱、验证码、Token、Cookie 和密钥不出现在 UI 日志、错误、截图和公开仓库。
- 登录、失效、退出和跨站跳转反馈一致。
- 收集字段最小化并说明用途。

## 15. Logo

正式 Logo 尚未冻结，最低要求：

- 有可独立使用的图形符号。
- 24px 可识别。
- 不复制或改造河南大学校徽。
- 不采用容易造成官方误认的印章式构图。
- 提供 SVG、透明 PNG、单色和反白。
- 可与 `HENU Kit` 字标组合，也可用于 favicon。

旧“对不起，我是外包”字标可作为 Community Edition 彩蛋，不作为正式主标。

## 16. 非官方声明位置

| 场景 | 要求 |
|---|---|
| 首页 | 首屏或首屏后的第一个可信信息区出现完整声明 |
| 全站页脚 | 固定短版声明 |
| 登录和支付 | 操作前再次明确主体 |
| README | 项目简介后直接出现 |
| 海报和二维码 | 使用短版声明 |

声明需清晰可见，但不使用警告红或强制弹窗制造不必要风险感。

## 17. 设计交付与验收

开发前至少具备：

- 目标用户、主任务和成功条件。
- 移动端与桌面端关键页面。
- Loading/Empty/Error/Success/Disabled。
- 登录、未登录和权限不足。
- token 对照。
- 文案、数据来源和更新时间。

合并前检查：

- 手机可独立完成主流程。
- 同一视区只有一个 Primary。
- 非官方声明位置正确。
- 键盘焦点、对比度和触控尺寸合格。
- 没有复制资料库或 QuizCraft 能力。
- Mermaid 图在 DOCX/PDF 中已渲染成图像，不是源码文本。

## 18. 治理

- 本文件使用语义版本。
- 颜色、Logo、导航、账户和模块边界是核心决策，修改必须团队评审。
- 新共享组件先证明至少两个真实复用场景。
- 临时业务样式必须设清理期限。
- 设计 token 的代码实现位于 `packages/design-tokens`。

## 19. 已确定事项

- 主色称为 Kit 墨绿，不称河大绿。
- HENU Kit 是学生自主运营的非官方项目。
- HENU Kit 是统一校园工具系统，不是简单导航集合。
- 资料库只展示资料。
- QuizCraft 是唯一刷题产品。
- 子产品可以独立部署，但统一设计、账户和跳转。
- 资料库保留轻量“打开资料册”。
- 计划使用 `henukit.cn`、`study.henukit.cn`、`quiz.henukit.cn` 和 `account.henukit.cn`。
- 统一账户考虑河南大学学生邮箱验证码登录。
