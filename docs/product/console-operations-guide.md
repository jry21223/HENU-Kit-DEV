# Console 运营指南

本页对应本轮成熟化候选。候选尚未完成生产发布；正在运行的版本与验收边界以[生产现状记录](../operations/CURRENT_PRODUCTION_STATE.md)为准。

## 从总览开始

打开 [Console](https://console.henukit.cn/)，使用已有账户正常登录。总览覆盖当前账户有权查看的业务，不按岗位拆分；每项操作仍由服务端核对权限与作用域。

“需要处理”优先呈现已确认的美食审核与未解决工单，旁边保留对应入口。数量附范围与来源时间。确认无事项时显示空状态；读取失败时说明未能确认，不能把它当成零。

业务概况提供平台、资料、通知、会员与积分等入口。平台收件箱的本页计数与全量统计分开；通知排队不表示送达。摘要接线、请求标识和权限代码在“连接与诊断”中按需展开。

## 常用路径

| 事项 | 路径与核对要点 |
| --- | --- |
| 美食运营 | 从总览或导航进入美食运营，确认校区、可见性与队列，再打开具体内容。总览是全局事实；工作台有载入上限，不能用当前列表长度代替全量待办。 |
| 账户工单 | 点击“查看未解决工单”进入相同的服务端状态筛选。页面分别显示全局匹配数、本次载入数及是否还有更多；标题与编号搜索只作用于当前载入窗口。选择具体工单后再查看详情和允许的操作。 |
| 平台运营 | 查看邮件状态聚合，按本页状态和页码查看收件箱引用。当前来源尚未接入，不能从引用直接进入来源处理；返回或刷新时保留已支持的筛选、分页与快照上下文。 |
| 校园通知 | 进入通知工作台查看版本和审核状态。分发结果区分排队与送达；未配置时显示接线限制，不提供虚假的成功反馈。 |
| 会员与积分 | 先选择并核对目标账户。会员页可查看当前权益；积分页仅在调整成功或恢复结果后展示本次余额与一笔记账，不提供调整前余额查询或完整账本。只执行当前账户有权进行的操作；会员身份本身不提供管理权限。 |
| 学习资料 | 公开资料目录可独立浏览。资料管理未就绪时，不展示可提交的管理表单；即使服务报告能力就绪，当前界面尚未接入时也会说明限制。 |

## 遇到问题时

- **暂时无法验证权限：** 使用“重试连接”。验证未完成时不展示私有业务内容；这与服务端明确拒绝访问不同。
- **会话失效：** 按页面指引正常登录，返回经过校验的原位置。切换账户后重新确认目标与上下文。
- **某个模块失败：** 查看该项提示，仍可使用其余已确认模块；需要时进入对应工作台核对。来源时间不变的新请求不代表数据已经更新。
- **提交结果待确认：** 先使用现有结果查询或恢复入口，不用连续点击制造新请求。页面只有核到真实结果才显示成功。
- **内容已被其他人修改：** 重新读取当前详情，核对新版本后再决定操作，不把旧页面覆盖到新内容上。

刷新、返回与恢复会保留已支持的筛选及操作上下文。具体错误如需排查，可展开诊断详情；不要在公开反馈中附带个人、支付或登录信息。
