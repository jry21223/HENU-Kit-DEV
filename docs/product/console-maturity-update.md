# Console 本轮改进

**候选预告，尚未完成生产发布。** 实际运行版本及未验项目见[生产现状记录](../operations/CURRENT_PRODUCTION_STATE.md)。

打开后台，先看到需要处理的业务，再进入相应工作台。本轮总览用有范围与来源时间的美食、工单等事实替代重复的摘要状态面板；连接和诊断信息收进按需展开的详情。

- **数量能核对。** 全局数量、本次载入窗口和本页计数分别说明；入口携带已支持的筛选，不把列表长度当全部业务规模。
- **失败说清楚。** 单个模块超时不拖垮其余内容；未知、确认零、无权限与未接入分别呈现。
- **操作能恢复。** 工单、美食、会员、积分和通知沿用已有业务与权限，补齐结果待确认、重复提交、并发变更和返回上下文的处理。
- **入口更诚实。** 公开资料目录与资料管理分开，管理未就绪时不展示假表单；通知排队不冒充送达。

继续复用 Kit 现有界面和导航，没有增加新的审批或复核队列。日常路径与故障处理见[Console 运营指南](console-operations-guide.md)。
