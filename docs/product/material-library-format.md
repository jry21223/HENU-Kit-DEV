# 资料库格式规范

> 配套工具：`libraryctl`（`scripts/libraryctl/`）
> 最后更新：2026-07-10

## 目录结构

```
资料库/
  00_模板/              模板文件（知识点模板、TeX模板等）
  01_收件箱/            待处理入口
    00_待分类/
    01_待去重/
    02_待确认课程/
  02_学校库/            按 学校 → 学院 → 阶段 → 学期 → 课程 组织
    01_河南大学/
      01_软件学院/
        00_学院公共资料/
        01_大一/
          01_上学期/
          02_下学期/
        02_大二/
        03_大三/
        04_大四/
  90_公共资料/          跨学院、跨课程通用资料
  99_全局归档/          历史归档
```

**核心原则：目录按培养方案阶段走，文件按资料年份走。**

- `大一 / 大二 / 大三` = 培养方案阶段
- `2022 / 2023 / 2024` = 真题年份（只体现于文件名）

## `course.yaml` 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `school` | string | ✅ | 学校名称 |
| `college` | string | ✅ | 学院名称 |
| `stage` | enum | ✅ | 培养方案阶段：`大一` `大二` `大三` `大四`（非入学级） |
| `semester` | enum | ✅ | 学期：`上学期` `下学期` |
| `course_name` | string | ✅ | 课程名称 |
| `course_aliases` | string[] | | 课程别名 |
| `applicable_majors` | string[] | | 适用专业 |
| `teacher` | string | | 授课教师 |
| `exam_type` | string[] | | 常见考试题型 |
| `status` | enum | | 整理状态：`collecting` `active` `complete` `archived` |
| `maintainer` | string | | 维护人 |
| `notes` | string | | 备注 |

## `materials.csv` 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `local_id` | string | ✅ | 本地编号 |
| `title` | string | ✅ | 网页展示标题 |
| `type` | enum | ✅ | 资料类型 |
| `status` | enum | ✅ | 处理状态 |
| `year` | string | | 资料年份 |
| `path` | string | ✅ | 相对课程目录的文件路径 |
| `source_note` | string | | 来源说明 |
| `sha256` | string | | 文件哈希 |
| `web_id` | string | | 网页资料ID |
| `notes` | string | | 备注 |

### 合法 `type` 值

`真题` `样卷` `讲义` `答案解析` `课件` `笔记` `题库` `实验资料` `其他`

### 合法 `status` 值

`raw` `pending` `reviewed` `published` `archived`

### `path` 路径边界

- `path` 必须是相对当前课程目录的非空路径，不能使用 POSIX 绝对路径、Windows 盘符路径或 UNC 路径。
- `/` 和 `\\` 都按路径分隔符处理；任何独立的 `..` 路径段和 NUL 字节都会被拒绝。
- 已存在文件会检查真实路径。课程目录内的符号链接如果最终指向课程目录外，校验失败。
- `validate` 与 `export-web` 共用 `safe-path.mjs` 的同一边界；不能通过跳过 `validate` 导出不安全路径。
- 导出 manifest 时，合法相对路径统一写成 `/` 分隔形式。

可重复运行路径边界测试：

```bash
npm run test:libraryctl
```

## 文件命名规范

```
{课程名}_{资料类型}_{年份或主题}_{标题}.{扩展名}
```

规则：
1. 中文保留
2. 空格 → `_`
3. `/ \ : * ? " < > |` → `-`
4. 连续下划线合并
5. 扩展名统一小写
6. 不硬编年份
7. 不写"最终版""最新版""改完版"

### 示例

```
离散数学_真题_2023_期末试卷.pdf
离散数学_真题_2024_期末试卷_含答案.pdf
高等数学A二_样卷_年份待确认_期末试卷.pdf
离散数学_真题_年份待确认_期末试卷.pdf
JavaWeb_实验资料_Servlet项目.zip
离散数学_讲义_图论基础.pdf
```

## 真题命名特殊规则

真题年份写入文件名，不确定则写 `年份待确认`：

```
{课程名}_真题_{年份}_{考试类型}_{补充说明}.{扩展名}
```

示例：
```
离散数学_真题_2022_期末试卷.pdf
离散数学_真题_2023_期末试卷_含答案.pdf
高等数学A二_真题_2024_期末试卷_回忆版.pdf
离散数学_真题_年份待确认_期末试卷.pdf
```

## 按专业拆分规则

只有当**同一学院、同一年级阶段、同一课程名，但不同专业考试内容明显不同**时，才额外拆：

```
离散数学_软件工程方向/
离散数学_网络工程方向/
```

不要默认按专业拆目录。
