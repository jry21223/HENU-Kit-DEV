# 通用学科期末复习包模板

这是一个面向高校课程期末复习资料生产的通用模板包。它用于把任意课程的样卷、例题、知识点整理、课后题、老师画重点或复习提纲，整理成可交付的复习产品包。

模板不绑定具体学校、学院、课程、教师、学生或个人署名。发布到公开仓库前，请继续保持所有示例内容为占位符，不要提交真实试卷扫描件、内部资料、学生信息、订单数据、账号密钥或未授权的课程材料。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `templates/final-review-notes-template.tex` | 通用复习知识点讲义 LaTeX 模板。包含考试结构、考点优先级、模块化知识点、题型模板、公式速查、易错点、复习计划和考前速记清单。 |
| `templates/final-mock-exam-template.tex` | 通用模拟卷 LaTeX 模板。包含试卷封面、题型区、答案解析区和可配置水印。 |
| `skills/subject-final-review/SKILL.md` | 通用“学科期末复习包生成”Skill。适用于数学、物理、计算机、英语、人文社科、经管法等课程，不针对单一学科。 |

## 敏感信息清理原则

发布到 GitHub 前至少检查以下内容：

1. 不保留个人署名、真实姓名、学号、手机号、邮箱、微信、QQ、支付信息或账号密钥。
2. 不保留具体学校、学院、专业、班级、教师姓名，除非这些信息本来就是公开且允许发布。
3. 不提交真实试卷原图、回忆版题库、内部答案、课程群资料或未经授权的版权内容。
4. 不提交生成后的付费资料 PDF、订单数据、用户下载记录或后台导出的运营数据。
5. 水印默认使用中性文案：`仅供个人复习使用｜请勿商用传播`。需要个人署名时，在私有生成流程里再覆盖变量。
6. 所有课程信息使用占位符，例如 `{{课程名称}}`、`{{学校/学院}}`、`{{考试方式}}`。

## 使用流程

1. 复制模板文件到某门课程的工作目录。
2. 先根据样卷和资料识别课程信息、题型结构、分值结构、难度和考点矩阵。
3. 用 `final-review-notes-template.tex` 生成考前复习知识点讲义。
4. 用 `final-mock-exam-template.tex` 分别生成模拟卷一、模拟卷二，并附完整答案解析。
5. 渲染 PDF 后按下面的命名规范输出。
6. 最后做质量检查，确认题型分值一致、答案完整、没有照搬旧题、PDF 可打开。

## 推荐输出命名

```txt
{{课程名称}}_考前复习知识点讲义.pdf
{{课程名称}}_模拟卷一_含答案解析.pdf
{{课程名称}}_模拟卷二_含答案解析.pdf
{{课程名称}}_期末复习包.zip
```

## LaTeX 编译建议

推荐使用 XeLaTeX：

```bash
xelatex final-review-notes-template.tex
xelatex final-review-notes-template.tex
xelatex final-mock-exam-template.tex
xelatex final-mock-exam-template.tex
```

中文字体默认使用 Noto CJK。若本地缺少字体，可以把模板中的字体设置改成系统可用中文字体，例如思源宋体、宋体、黑体、苹方或微软雅黑。

## 质量检查清单

- 是否识别了最新样卷和最新文字说明。
- 是否明确标注无法确定的信息为“未明确”。
- 是否严格匹配样卷题型、题量和分值。
- 两套模拟卷总分是否正确。
- 每道题是否都有答案。
- 大题、计算题、程序题、论述题是否有完整解析。
- 讲义是否有考点优先级，而不是平铺教材。
- 是否包含题型方法模板、公式速记、易错点和考前复习计划。
- 是否避免直接复制旧题、只改数字、只换变量名或只打乱选项。
- 两套卷考点是否错开但难度相当。
- PDF 是否能正常打开。
- 文件名是否符合交付规范。
- Git 提交前是否通过敏感信息扫描。

## 推荐敏感信息扫描命令

```bash
# 常见个人信息或私有痕迹关键词，按项目实际补充
grep -RInE "姓名|学号|手机号|微信|QQ|邮箱|密码|secret|token|api[_-]?key|private|付款|订单" .

# 检查是否残留个人署名或特定学校名
grep -RInE "真实姓名|个人署名|学校全称|学院全称|教师姓名" .
```

扫描结果需要人工判断。模板中的占位词可以保留，真实信息必须移除。
