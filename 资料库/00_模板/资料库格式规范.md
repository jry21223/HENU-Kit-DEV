# 资料库格式规范

## 总体结构

```text
资料库/
  00_模板/
  01_高等数学A（二）/
  02_离散数学/
  ...
  99_综合资料/
```

每门课内部固定为：

```text
课程目录/
  00_成品复习包/
  01_知识点库/
  02_原始资料/
    01_样卷与真题/
    02_课件/
    03_题库与练习/
    04_教材与题解/
    05_笔记与总结/
    06_学习计划/
    08_网页与源码/
    90_源文件/
    98_图片资料/
    99_压缩包/
    97_待确认/
```

## 成品复习包命名

严格沿用 `final-review-template-kit` 的输出格式：

```text
课程名_考前复习知识点讲义.pdf
课程名_模拟卷一_含答案解析.pdf
课程名_模拟卷二_含答案解析.pdf
课程名_期末复习包.zip
```

## 原始资料命名

```text
课程名_资料类型_年份或章节_主题_补充说明.扩展名
```

能确认的信息才写入文件名，不硬编年份和卷别。

## 知识点库

知识点源文件使用 Markdown；最终 PDF 输出使用 TeX 模板。

- `00_模板/知识点模板.md`：单个知识点整理模板
- `00_模板/知识点索引模板.csv`：知识点检索表模板
- `00_模板/复习包TeX模板/`：讲义与模拟卷的最终排版模板

## 去重规则

按文件大小分组，对可能重复的文件计算 SHA256。内容完全一致的文件只归档一份，并写入 `重复文件记录.csv`。
