## K001 命题与真值

### 来源
- 文件：离散数学.pdf
- 页码：9-14页
- 相关习题：数理逻辑习题课.pdf，2-4页

### 1. 概念定义
命题是判断结果唯一的陈述句。命题的判断结果称为真值，真值只有两种：真和假。真值为真的命题叫真命题，真值为假的命题叫假命题。

### 2. 关键规则
- 是命题：必须是陈述句，并且真值唯一确定。
- 不是命题：疑问句、祈使句、感叹句、悖论、含未定变量且真值不确定的语句。

### 3. 课件中的例子
- "√2 是无理数。"是真命题。
- "2+5=8。"是假命题。
- "x+5>3。"真值不确定，不是命题。
- "你有铅笔吗？"是疑问句，不是命题。

### 4. 易错点
- "陈述句"不一定都是命题；若判断结果不唯一，也不是命题。
- "假命题"仍然是命题；是否为命题与真假无关。

### 5. 学习建议
判断语句是否为命题时，先问两个问题：是否陈述句？真值是否唯一确定？两个都满足才是命题。

### 6. 与其他知识点的关系
命题是命题符号化、复合命题、命题公式、真值表、推理理论的起点。

## K002 命题符号化

### 来源
- 文件：离散数学.pdf
- 页码：14页
- 相关习题：数理逻辑习题课.pdf，3-6页

### 1. 概念定义
命题符号化是用小写英文字母 p, q, r, ... 表示简单命题，并在复合命题中用逻辑联结词连接这些符号。

### 2. 关键规则
- p, q, r 通常表示原子命题。
- 用 1 表示真，用 0 表示假。
- 符号化时要先明确每个命题符号的含义。

### 3. 课件中的例子
设：p：我上街；q：我去书店看看；r：我很累。  
"如果我上街，我就去书店看看，除非我很累"可转化为命题公式，课件中给出形式如 `(p ∧ ¬r) → q`，也可等价分析为 `¬r → (p → q)`，两种表达需结合语义审查。

### 4. 易错点
- "除非"类语句是符号化高频易错点。
- 不要把自然语言顺序机械对应为公式顺序，应先分析条件关系。

### 5. 学习建议
做符号化题时固定三步：定义命题符号 → 找联结词 → 判断主联结词。

### 6. 与其他知识点的关系
命题符号化直接服务于真值表、等值演算、范式和推理证明。

## K003 五种基本联结词

### 来源
- 文件：离散数学.pdf
- 页码：15-31页

### 1. 概念定义
命题逻辑中常用五种联结词：否定、合取、析取、蕴涵、等价。

### 2. 关键公式 / 真值规则
| 联结词 | 符号 | 读法 | 真值特点 |
|---|---|---|---|
| 否定 | ¬p | 非 p | p 真则 ¬p 假；p 假则 ¬p 真 |
| 合取 | p∧q | p 并且 q | 两者都真才真 |
| 析取 | p∨q | p 或 q | 至少一个真即真 |
| 蕴涵 | p→q | 若 p 则 q | 只有 p 真 q 假时为假 |
| 等价 | p↔q | p 当且仅当 q | p、q 真值相同才真 |

### 3. 易错点
- p→q 不是因果关系，而是真值函数。
- 当前件 p 为假时，p→q 恒为真。
- p∨q 在课件中通常按相容析取处理，即"至少一个真"。

### 4. 学习建议
必须熟记五种联结词真值表，尤其是蕴涵和等价。考试中很多错误来自对 p→q 的真假判断错误。

### 5. 与其他知识点的关系
联结词是真值表、公式类型、等值式、范式和推理规则的语法基础。

## K004 命题公式与真值表

### 来源
- 文件：离散数学.pdf
- 页码：32-43页
- 文件：数理逻辑习题课.pdf
- 页码：7-9页

### 1. 概念定义
命题公式是由命题变项、命题常项和联结词按合式规则构成的表达式。真值表用于列出公式在所有赋值下的真值。

### 2. 关键规则
- n 个命题变项共有 2^n 个赋值。
- 每一行赋值对应公式的一个真值。
- 真值表可判断公式类型、公式等值、推理是否正确。

### 3. 课件中的例子
数理逻辑习题课中出现题目：计算公式 `((¬p→q)→(¬q∨p))` 的成真赋值个数。做法是列 p、q 的 4 种赋值并计算公式真值。

### 4. 易错点
- 真值表行数漏写。
- 联结词优先级错误。
- 蕴涵公式真假判断错误。

### 5. 学习建议
真值表题不要跳步。先列变项，再逐列计算子公式，最后计算主联结词。

### 6. 与其他知识点的关系
真值表是命题逻辑中最基础、最通用的判定方法。

## K005 公式类型：重言式、矛盾式、可满足式

### 来源
- 文件：离散数学.pdf，32-43页
- 文件：1.3 命题逻辑等值演算.pdf，11-13页

### 1. 概念定义
- 重言式：任意赋值下都为真。
- 矛盾式：任意赋值下都为假。
- 可满足式：至少存在一个赋值使公式为真。
- 非重言式的可满足式：有真也有假。

### 2. 关键规则
- A 为重言式 ⇔ A ⇔ 1。
- A 为矛盾式 ⇔ A ⇔ 0。
- A 可满足 ⇔ 至少有一个成真赋值。

### 3. 课件中的例子
- `q∧¬(p→q)` 经等值演算可化为 `0`，因此是矛盾式。
- `(p→q)↔(¬q→¬p)` 是重言式。
- `((p∧q)∨(p∧¬q))∧r` 可化为 `p∧r`，不是重言式也不是矛盾式，而是非重言式的可满足式。

### 4. 易错点
- 可满足式不等于重言式。
- 矛盾式没有成真赋值。
- 公式类型判断可以用真值表，也可以用等值演算。

### 5. 学习建议
先用等值演算化简；若化不动，再列真值表。考试选择题常用特殊赋值快速判断。

### 6. 与其他知识点的关系
公式类型是主范式、推理正确性和等值判断的基础。

## K006 等值式与基本等值式

### 来源
- 文件：1.3 命题逻辑等值演算.pdf
- 页码：1-7页

### 1. 概念定义
若 A↔B 为重言式，则称 A 与 B 等值，记为 A⇔B，并称 A⇔B 为等值式。

### 2. 关键公式 / 规则
常用基本等值式包括：

| 名称 | 形式 |
|---|---|
| 双重否定律 | ¬¬A ⇔ A |
| 等幂律 | A∨A ⇔ A；A∧A ⇔ A |
| 交换律 | A∨B ⇔ B∨A；A∧B ⇔ B∧A |
| 结合律 | (A∨B)∨C ⇔ A∨(B∨C)；(A∧B)∧C ⇔ A∧(B∧C) |
| 分配律 | A∨(B∧C) ⇔ (A∨B)∧(A∨C)；A∧(B∨C) ⇔ (A∧B)∨(A∧C) |
| 德摩根律 | ¬(A∨B) ⇔ ¬A∧¬B；¬(A∧B) ⇔ ¬A∨¬B |
| 蕴涵等值式 | A→B ⇔ ¬A∨B |
| 等价等值式 | A↔B ⇔ (A→B)∧(B→A) |
| 假言易位 | A→B ⇔ ¬B→¬A |

### 3. 易错点
- 德摩根律中联结词要互换。
- 蕴涵式消去后是 `¬A∨B`，不是 `A∨B`。
- 等值式两边不要求形式相同，只要求真值表完全相同。

### 4. 学习建议
基本等值式需要熟练到可直接调用。尤其要背牢：德摩根律、蕴涵等值式、假言易位、分配律。

### 5. 与其他知识点的关系
它是等值演算、范式转换、主范式求解和推理证明的核心工具。

## K007 等值演算与置换规则

### 来源
- 文件：1.3 命题逻辑等值演算.pdf
- 页码：7-14页

### 1. 概念定义
等值演算是由已知等值式推出新的等值式的过程。置换规则：若 A⇔B，则在公式中可用 B 置换 A 的出现位置，保持整体等值。

### 2. 关键规则
- 每一步必须保持等值。
- 可从左式演算到右式，也可从右式演算到左式。
- 证明不等值不能只说"化不到"，应找一个赋值使两式真值不同。

### 3. 课件中的例子
证明：`p→(q→r) ⇔ (p∧q)→r`。

推导：
```text
p→(q→r)
⇔ ¬p∨(¬q∨r)
⇔ (¬p∨¬q)∨r
⇔ ¬(p∧q)∨r
⇔ (p∧q)→r
```

### 4. 易错点
- 等值演算不能使用只在某些赋值下成立的变形。
- 不要把蕴涵推理和等值变形混用。

### 5. 学习建议
写证明时在每步右侧标注所用等值式名称，训练严谨性。

### 6. 与其他知识点的关系
等值演算是范式转换和公式类型判断的主要技术。

## K008 析取范式与合取范式

### 来源
- 文件：1.3 命题逻辑等值演算.pdf
- 页码：15-25页

### 1. 概念定义
- 文字：命题变项或其否定。
- 简单合取式：有限个文字的合取。
- 简单析取式：有限个文字的析取。
- 析取范式：若干简单合取式的析取。
- 合取范式：若干简单析取式的合取。

### 2. 关键规则
- 析取范式与合取范式统称范式。
- 一个公式的范式不唯一。
- 任一命题公式都可化为析取范式和合取范式。

### 3. 易错点
- 单个文字既可看作简单合取式，也可看作简单析取式。
- 普通范式不唯一，不能把某个普通范式误认为唯一答案。

### 4. 学习建议
转换范式常用步骤：消去 → 和 ↔；否定内移；用分配律整理。

### 5. 与其他知识点的关系
范式是主范式的前置知识，主范式又用于判断等值、求成真/成假赋值。

## K009 主析取范式与主合取范式

### 来源
- 文件：1.3 命题逻辑等值演算.pdf
- 页码：26-45页

### 1. 概念定义
主析取范式是由公式成真赋值对应的极小项析取而成的唯一范式。主合取范式是由公式成假赋值对应的极大项合取而成的唯一范式。

### 2. 关键规则
- 极小项：每个命题变项出现一次，且以原变量或否定形式出现在合取式中。
- 极大项：每个命题变项出现一次，且以原变量或否定形式出现在析取式中。
- 主析取范式由成真赋值决定。
- 主合取范式由成假赋值决定。

### 3. 课件中的例子
课件用主范式判断公式等值：若两个公式主析取范式相同，则两公式等值；若不同，则不等值。

### 4. 易错点
- 极小项编号与赋值顺序有关，变量顺序必须固定。
- 主析取范式对应成真赋值，主合取范式对应成假赋值，不要反过来。

### 5. 学习建议
考试中建议把变量顺序写在草稿开头，例如 `(p,q,r)`，避免极小项编号混乱。

### 6. 与其他知识点的关系
主范式是判断公式类型和等值的重要工具，也可用于推理正确性判断。

## K010 推理形式结构

### 来源
- 文件：1.7 推理理论.pdf
- 页码：1-5页

### 1. 概念定义
推理是从前提出发推出结论的思维过程。形式结构通常写作：前提 A1,A2,...,Ak，结论 B。

推理正确当且仅当：
```text
A1 ∧ A2 ∧ ... ∧ Ak → B
```
为重言式。

### 2. 判断方法
- 真值表法。
- 等值演算法。
- 主析取范式法。
- 构造证明法。

### 3. 易错点
- 推理正确不等于结论本身一定为真。
- 推理正确的含义是：当前提全真时，结论不可能为假。

### 4. 学习建议
看到自然语言推理题，先符号化，再写出"前提合取 → 结论"的形式结构。

### 5. 与其他知识点的关系
推理理论是命题逻辑的综合应用，并为一阶逻辑推理做准备。

## K011 推理定律与推理规则

### 来源
- 文件：1.7 推理理论.pdf
- 页码：8-11页

### 1. 概念定义
推理定律是常用的重言蕴涵式，推理规则是构造证明时允许使用的合法步骤。

### 2. 关键规则
| 名称 | 形式 |
|---|---|
| 附加律 | A ⇒ A∨B |
| 化简律 | A∧B ⇒ A |
| 假言推理 | (A→B)∧A ⇒ B |
| 拒取式 | (A→B)∧¬B ⇒ ¬A |
| 析取三段论 | (A∨B)∧¬B ⇒ A |
| 假言三段论 | (A→B)∧(B→C) ⇒ A→C |
| 等价三段论 | (A↔B)∧(B↔C) ⇒ A↔C |
| 构造性二难 | (A→B)∧(C→D)∧(A∨C) ⇒ B∨D |

### 3. 易错点
- 假言推理是 A→B 与 A 推出 B；不能由 A→B 与 B 推出 A。
- 拒取式是 A→B 与 ¬B 推出 ¬A；不能由 A→B 与 ¬A 推出 ¬B。

### 4. 学习建议
把推理规则和常见错误对应记忆：肯定后件、否定前件通常无效。

### 5. 与其他知识点的关系
推理规则是构造证明法、附加前提证明法、归谬法的基础。

## K012 构造证明方法

### 来源
- 文件：1.7 推理理论.pdf
- 页码：12-24页

### 1. 概念定义
构造证明是按规则写出命题公式序列，每一步都是前提、已证结论或由推理规则推出的新公式。

### 2. 三种证明法
- 直接证明法：从前提出发直接推出结论。
- 附加前提证明法：证明 A→B 时，可附加 A 为前提，再证明 B。
- 归谬法：假设结论否定成立，推出矛盾。

### 3. 课件中的例子
"天气很好且他没去公司，所以他去钓鱼"类题，应先设命题符号，再列出前提，最后用推理规则推出结论。

### 4. 易错点
- 附加前提证明法不能随意添加与目标无关的前提。
- 归谬法必须推出明确矛盾，例如 A 与 ¬A。

### 5. 学习建议
证明题建议用两列表：左列写步骤编号和公式，右列写理由。

### 6. 与其他知识点的关系
构造证明思想会延续到集合恒等式证明、关系性质证明和图论证明题中。
