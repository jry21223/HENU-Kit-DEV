## K019 集合定义与表示

### 来源
- 文件：集合论.pdf
- 页码：1-8页

### 1. 概念定义
集合可以理解为由一些确定对象组成的整体。组成集合的对象称为元素或成员。

### 2. 表示方法
- 列元素法：A={a,b,c,d}。
- 谓词表示法：B={x | P(x)}，表示使 P(x) 为真的 x 构成的集合。

### 3. 元素基本性质
- 互异性：相同元素只算一个。
- 可分性：对象是否属于集合必须可判定。
- 无序性：元素排列顺序无关。

### 4. 易错点
- `{1,1,2}={1,2}`。
- `{1,2}={2,1}`。
- 谓词表示法必须明确变量范围。

### 5. 学习建议
遇到集合题先明确：集合中元素是什么类型，是数、集合、序偶，还是函数。

### 6. 与其他知识点的关系
集合表示是后续集合运算、笛卡尔积、关系和函数的基础。

## K020 元素与集合、集合间关系

### 来源
- 文件：集合论.pdf
- 页码：9-14页

### 1. 概念定义
元素与集合之间用属于关系表示：x∈A 或 x∉A。集合之间用包含关系表示：A⊆B、A⊂B、A=B。

### 2. 关键规则
- A⊆B ⇔ ∀x(x∈A → x∈B)。
- A=B ⇔ A⊆B 且 B⊆A。
- A⊂B ⇔ A⊆B 且 A≠B。

### 3. 课件中的易错例子
设 A={a,{a},{a,b},{{a,b},c}}，需要判断 `{a}∈A`、`{a}⊆A` 等表达式。这类题关键是区分"元素"与"子集"。

### 4. 易错点
- ∈ 与 ⊆ 是不同层级关系。
- `{a}` 是一个集合，不等于 a。
- `{a}∈A` 与 `{a}⊆A` 可能真假不同。

### 5. 学习建议
看到花括号嵌套题，要逐层读，不要凭直觉判断。

### 6. 与其他知识点的关系
包含关系是集合恒等式证明、划分、等价类、商集的基础。

## K021 空集、全集、幂集

### 来源
- 文件：集合论.pdf
- 页码：15-17页

### 1. 概念定义
- 空集：不含任何元素的集合，记为 ∅。
- 全集：在给定问题中包含所有讨论对象的集合。
- 幂集：集合 A 的所有子集构成的集合，记为 P(A)。

### 2. 关键规则
- ∅ 是任何集合的子集。
- 若 |A|=n，则 |P(A)|=2^n。
- A∈P(A) 不一定成立；A⊆A 一定成立，因此 A 是 P(A) 的元素。

### 3. 易错点
- ∅ 与 {∅} 不同。
- ∅∈A 和 ∅⊆A 不是一回事。
- P(A) 的元素是 A 的子集。

### 4. 学习建议
幂集题先列所有子集，再判断属于或包含。

### 5. 与其他知识点的关系
幂集在划分、关系集合、函数集合 B^A 中都会出现。

## K022 集合运算与恒等式

### 来源
- 文件：集合论.pdf
- 页码：18-43页

### 1. 概念定义
集合基本运算包括并、交、差、补、对称差。

### 2. 关键公式
| 运算 | 定义 |
|---|---|
| 并 | A∪B={x | x∈A 或 x∈B} |
| 交 | A∩B={x | x∈A 且 x∈B} |
| 差 | A−B={x | x∈A 且 x∉B} |
| 补 | ¬A 或 A^c，取决于全集 E |
| 对称差 | A⊕B=(A−B)∪(B−A) |

### 3. 证明方法
证明 A=B 通常用互相包含：
```text
先证 A⊆B，再证 B⊆A。
```

### 4. 易错点
- 补集必须相对于全集。
- A−B 与 B−A 一般不同。
- 文氏图能帮助理解，但正式证明要用元素法或等值演算。

### 5. 学习建议
集合恒等式与命题逻辑等值式高度对应，可把 ∈ 转化为命题条件来证明。

### 6. 与其他知识点的关系
集合运算思想迁移到关系运算、图的顶点集/边集运算中。
