## K013 个体词、谓词、量词

### 来源
- 文件：2.1.pdf
- 页码：1-18页

### 1. 概念定义
一阶逻辑把命题内部结构进一步拆开，用个体词表示对象，用谓词表示对象性质或对象间关系，用量词表示数量范围。

### 2. 关键概念
- 个体常项：具体对象，常用 a,b,c 表示。
- 个体变项：抽象对象，常用 x,y,z 表示。
- 个体域：个体变项的取值范围。
- 谓词：表示性质或关系，如 F(x)、L(x,y)。
- 全称量词：∀x，表示"所有 x"。
- 存在量词：∃x，表示"存在 x"。

### 3. 易错点
- 个体域不同，公式含义可能不同。
- 谓词不是命题，只有给定个体或加上量词后才可能成为命题。

### 4. 学习建议
符号化前必须先确定个体域，再定义谓词。

### 5. 与其他知识点的关系
这是合式公式、解释、量词等值式和前束范式的基础。

## K014 一阶逻辑命题符号化

### 来源
- 文件：2.1.pdf，4-18页
- 文件：2.3 一阶逻辑等值式与前束范式.pdf，4页、7页

### 1. 概念定义
一阶逻辑命题符号化是用谓词、个体词和量词表示自然语言中的对象、性质和数量关系。

### 2. 常见表达
| 自然语言 | 常见形式 |
|---|---|
| 所有 A 都是 B | ∀x(A(x)→B(x)) |
| 有些 A 是 B | ∃x(A(x)∧B(x)) |
| 没有 A 是 B | ¬∃x(A(x)∧B(x))，等价于 ∀x(A(x)→¬B(x)) |
| 不是所有 A 都是 B | ¬∀x(A(x)→B(x))，等价于 ∃x(A(x)∧¬B(x)) |

### 3. 课件中的例子
"没有不犯错误的人"可设 F(x)：x 是人，G(x)：x 犯错误，符号化为：
```text
¬∃x(F(x)∧¬G(x))
```
也可等价写为：
```text
∀x(F(x)→G(x))
```

### 4. 易错点
- "所有 A 是 B"通常是蕴涵，不是合取。
- "有些 A 是 B"通常是合取，不是蕴涵。
- 否定量词时，量词要互换。

### 5. 学习建议
记住两条核心模板：全称用 →，存在用 ∧。

### 6. 与其他知识点的关系
符号化是后续一阶逻辑等值式和前束范式题的基础。

## K015 项、原子公式与合式公式

### 来源
- 文件：2.1.pdf
- 页码：19-30页

### 1. 概念定义
项是可表示个体对象的表达式；原子公式是由谓词作用于项形成的最基本公式；合式公式是在原子公式基础上按联结词和量词规则构成的公式。

### 2. 关键规则
- 原子公式如 P(x)、L(x,y)。
- 若 A、B 是合式公式，则 ¬A、A∧B、A∨B、A→B、A↔B 是合式公式。
- 若 A 是合式公式，则 ∀xA、∃xA 是合式公式。

### 3. 易错点
- 量词后必须跟公式，而不是孤立变量。
- 谓词的元数要匹配参数个数。

### 4. 学习建议
判断是否为合式公式时，从最内层原子公式开始检查。

### 5. 与其他知识点的关系
合式公式是解释、赋值、前束范式转换的对象。

## K016 自由变元、约束变元与解释

### 来源
- 文件：2.1.pdf
- 页码：19-38页

### 1. 概念定义
一个变元若处在对应量词辖域内，则该出现是约束出现；否则是自由出现。没有自由变元的公式称为闭式。

解释用于给定个体域、常项含义、函数符号含义和谓词符号含义。赋值用于指定自由变元取值。

### 2. 关键规则
- 同一变元在不同位置可能既有自由出现，也有约束出现。
- 闭式在给定解释下有确定真值。
- 含自由变元的公式需要赋值后才有真值。

### 3. 易错点
- 变量名相同不代表所有出现都受同一个量词约束，要看辖域。
- 换名时只能改约束变元，不能改变自由变元。

### 4. 学习建议
用括号标出量词辖域，再判断每个变元出现是自由还是约束。

### 5. 与其他知识点的关系
自由/约束变元判断直接影响量词辖域收缩、换名规则和前束范式。

## K017 一阶逻辑等值式

### 来源
- 文件：2.3 一阶逻辑等值式与前束范式.pdf
- 页码：1-7页

### 1. 概念定义
若 A↔B 为逻辑有效式，则称 A 与 B 等值，记为 A⇔B。

### 2. 关键公式
| 类型 | 公式 |
|---|---|
| 量词否定 | ¬∀xA(x) ⇔ ∃x¬A(x) |
| 量词否定 | ¬∃xA(x) ⇔ ∀x¬A(x) |
| 全称分配 | ∀x(A(x)∧B(x)) ⇔ ∀xA(x)∧∀xB(x) |
| 存在分配 | ∃x(A(x)∨B(x)) ⇔ ∃xA(x)∨∃xB(x) |

### 3. 量词辖域收缩与扩张
若 B 中不含 x 的自由出现，则：
```text
∀x(A(x)∨B) ⇔ ∀xA(x)∨B
∀x(A(x)∧B) ⇔ ∀xA(x)∧B
∃x(A(x)∨B) ⇔ ∃xA(x)∨B
∃x(A(x)∧B) ⇔ ∃xA(x)∧B
```

### 4. 易错点
- ∀ 对 ∨ 不总是分配；∃ 对 ∧ 不总是分配。
- 使用辖域收缩/扩张时，必须检查变量 x 是否在另一公式中自由出现。

### 5. 学习建议
做一阶等值变形题时，优先处理否定量词，再处理辖域和分配。

### 6. 与其他知识点的关系
一阶逻辑等值式是前束范式转换的核心依据。

## K018 前束范式

### 来源
- 文件：2.3 一阶逻辑等值式与前束范式.pdf
- 页码：8-15页

### 1. 概念定义
一阶逻辑公式若形如：
```text
Q1x1 Q2x2 ... Qkxk B
```
其中 Qi 是 ∀ 或 ∃，B 是不含量词的公式，则称该公式为前束范式。

### 2. 转换步骤
1. 消去 →、↔。
2. 否定内移到原子公式前。
3. 必要时换名，避免变量冲突。
4. 将量词逐步前移。
5. 得到量词前缀 + 无量词母式。

### 3. 易错点
- 不换名就前移量词，容易造成变量捕获。
- 不同量词之间一般不能随意交换顺序。

### 4. 学习建议
转换时先写"换名后公式"，再移动量词，避免一步到位出错。

### 5. 与其他知识点的关系
前束范式是处理一阶逻辑推理和公式标准化的基本形式。
