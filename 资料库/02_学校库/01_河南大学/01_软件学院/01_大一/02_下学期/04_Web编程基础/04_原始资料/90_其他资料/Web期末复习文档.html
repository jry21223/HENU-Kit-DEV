HTML教程

超文本标记语言（英语：HyperText Markup Language，简称：HTML）是一种用于创建网页的标准标记语言，HTML 运行在浏览器上，由浏览器来解析。

根据它的发展历史，分为：

  • HTML 2.0 、HTML 3.2、HTML 4.01、HTML 5
  • XHTML 1.0、XHTML 1.1（XHTML是HTML过度xml的标记语言，它需要符合xml文档规则，XHTML1.0不能自定义标记）

1. HTML发展历史

HTML（超文本标记语言）的发展史，其实就是一部万维网自身演进和创新的缩影。下面，我为你梳理一下这段有趣的历史。

1.1. 起源：从一份简单的文档开始

一切都始于欧洲核子研究组织（CERN）。1989年，蒂姆·伯纳斯- Lee（Tim Berners-Lee）为了满足全球研究人员之间信息共享和协作的需求，提出了万维网的构想。作为这个构想的核心，他需要一种方法来创建和链接文档。

  • 1990-1991年：蒂姆·伯纳斯- Lee编写了一份名为“HTML标签”的文档，其中定义了大约20个用于标记网页的标签。这些标签借用了当时已有的一个更复杂的标记语言——标准通用标记语言（SGML）的语法，奠定了HTML的基础。
  • 1993年：HTML的第一个公开版本作为互联网工程任务组（IETF）的工作草案发布。同年，一个关键的创新发生了：当时还是大学生的马克·安德森（Marc Andreessen）为他的Mosaic浏览器引入了 <img> 标签，让网页可以显示图片，这一举动极大地丰富了网页的表现力。

有趣的是，HTML的版本号并不是从1.0开始的。因为在其发展初期，存在多个不同的版本，所以第一个正式的官方规范就被命名为 HTML 2.0，以便与这些非标准版本区分开来。

1.2. 快速发展与“浏览器大战”时期

1994年，蒂姆·伯纳斯- Lee创立了万维网联盟（W3C），开始对HTML进行标准化工作。90年代后半叶，随着Netscape Navigator和Internet Explorer两大浏览器的激烈竞争，HTML的版本也更新得十分频繁。

  • 1995年11月：HTML 2.0 作为RFC 1866正式发布。它吸纳了当时已在使用的诸多特性，例如基于表单的输入和 <img> 标签。
  • 1997年1月14日：W3C发布了 HTML 3.2 作为其首个推荐标准。这个版本为了兼容性，加入了许多由Netscape和Internet Explorer等浏览器引入的专有元素和属性（如字体、表格等）。
  • 1997年12月18日：HTML 4.0 发布。这个版本开始尝试“清理”标准，将一些纯粹用于控制表现的标签（如 <font>）标记为“过时”（deprecated），并鼓励使用层叠样式表（CSS）来控制网页的外观，实现了内容（HTML）与表现（CSS）的初步分离。
  • 1999年12月24日：HTML 4.01 发布，它对HTML 4.0进行了一些微小的修正，并成为当时最稳定、最广泛使用的HTML版本。

1.3. 弯路与转折：XHTML的尝试和WHATWG的诞生

HTML 4.01发布后，W3C认为HTML已经完成，决定将未来的工作转向基于XML的XHTML（可扩展超文本标记语言），希望用更严格、更规范的XML语法来重塑Web。

  • 2000-2001年：XHTML 1.0 和 XHTML 1.1 相继发布。XHTML 1.0 只是将HTML 4.01用XML语法重新表达，要求标签必须小写、属性必须加引号等。而XHTML 1.1则更严格，导致许多浏览器（尤其是当时主流的IE）无法正确解析。
  • 2004年：W3C接着推进 XHTML 2.0 的工作。但这个版本完全不向后兼容，试图创建一种全新的语言，这引起了Opera、Apple和Mozilla等浏览器厂商的强烈反对。他们向W3C提议扩展HTML以更好地支持Web应用，但遭到拒绝。于是，这些厂商联合起来，成立了一个独立的工作组——WHATWG（Web超文本应用技术工作组）。
  • 2004年起：WHATWG开始并行推进两个规范：Web Forms 2.0 和 Web Apps 1.0，它们旨在为HTML添加新功能以适应现代Web应用的需求。

1.4. 现代HTML：HTML的诞生与大一统

随着WHATWG的工作成果越来越受到欢迎，而W3C的XHTML 2.0项目陷入僵局，Web之父蒂姆·伯纳斯- Lee在2006年发表博客文章，承认从HTML走向XML的道路行不通。

  • 2008年：W3C接纳了WHATWG的工作，并与之合作发布了 HTML5 的第一份草案。WHATWG的两个规范也合并为HTML5。
  • 2009年：W3C正式宣布终止XHTML 2.0的工作，标志着这场路线之争的结束。
  • 2014年10月28日：历经近十年的开发和改进，HTML5 终于成为W3C的正式推荐标准。HTML5并不是一个从零开始的全新语言，而是在HTML4的基础上，增加了对视频、音频、绘图、地理位置、本地存储等现代Web功能的原生支持，并引入了一系列语义化标签（如 <article>, <section>, <nav>）。

此后，HTML的发展进入了一个新的阶段。W3C和WHATWG曾合作，也曾在2012年因发展理念不同而产生分歧。最终在2019年，双方达成协议，确立了WHATWG负责维护的“HTML Living Standard”（动态标准）将成为HTML的唯一官方标准，而W3C则作为该标准的批准者。这意味着HTML不再有像“HTML6”这样的新版本号，而是会持续不断地进行更新和演进。

了解完这段历史，你是不是也对HTML5带来的那些新功能更感兴趣了？比如，你想知道语义化标签具体怎么用，或者Canvas能画出什么样的效果吗？我们可以接着探讨。

2. HTML语法和构成

2.1. HTML实例 

<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <title>页面标题</title>
    </head>
    <body>
        <header><!-- 导航栏 --></header>
        <main><!-- 主要内容 --></main>
        <footer><!-- 页脚信息 --></footer>
    </body>
</html>

上面的代码保存在某个网页文件中，该文件的后缀名可以是：

  • .html
  • .htm
    建议使用 .html。

2.2. HTML元素构成

HTML 由一系列 elements 组成，这些元素相互可以嵌套，比如前面的示例。Html元素的结构为开始标签和结束标签及其中的内容，如：<p>My cat is very grumpy</p>。所有的元素即可用大写也可用小写，建议使用小写。

  1. HTML元素（双标签）语法：

    • 开始标签：HTML元素由起始标签start tag（首标签 opening tag）开始，如上面的<p>，它由元素的名称（在本例中为 p）包含在左尖括号和右尖括号中。
    • 结束标签：HTML元素以结束标签end tag（尾标签 closing tag）结尾，如上面的</p>，这与开始标记相同，只是它在元素名称之前包含一个正斜杠。
    • 内容：介于起始标签与结束标签之间的全部内容，叫做元素内容，如上面的My cat is very grumpy。

    需要保证元素的正确嵌套，下例是错误的：

    <p>My cat is <strong>very grumpy.</p></strong>

  2. HTML元素可拥有一些属性（attributes）：

    这里，class 是属性名称，editor-note 是属性值。

    多个属性之间用空格隔开，它们提供该元素的更多信息。
    属性总是在出现在起始标签里，它以名值对（name/value pair）的形式出现的，就像这样：name="value"。这里属性值用引号括起来。双引号、单引号都可以用，不过一般来说，双引号用得更多一些。对于某些特殊情况，比如属性值里包含有双引号，那么就只有使用单引号了：
    name='John "ShotGun" Nelson'

    下面列出了适用于大多数 HTML 元素的属性：

    属性 描述
    class 为html元素定义一个类名（classname）(类名可从样式文件引入)
    id 定义元素的唯一id
    style 规定元素的内部样式（inline style）

  3. 空元素

    有些元素没有内容，称为 void elements，这些元素只有一个单标签。比如 <img> 元素：

    <img src="images/firefox-icon.png" alt="My test image" />

    它包含两个属性，但没有结束 </img> 标记，也没有内部内容。其目的是将图片嵌入到 HTML 页面中出现的位置。

    还有一种元素，它的单标签中没有属性，比如：<br> 就是没有关闭标签的空元素，虽然<br>这种形式在所有的浏览器中都可以被正常解释，但为了标准起见，关闭空元素的正确方法是在开始标签中添加斜杠，比如 <br/>

  4. 块元素和行内元素
    html元素又分为块元素和行内元素，块元素总是在新行上开始，比如：<p>，而行内元素和其他元素都在同一行上，比如：

    <p>My cat is <strong>very</strong> grumpy.</p>

    效果：

    My cat is very grumpy.

  5. HTML 注释
    注释的目的是允许你在代码中添加注释来解释你的逻辑或编码。要编写 HTML 注释，请将其包含在特殊标记 <!-- 和 --> 中。
    例如：

    <p>I'm not inside a comment</p>
<!-- <p>I am!</p> -->

  6. 嵌套规则

    HTML元素可以互相嵌套，但必须遵循“先打开的后关闭”的原则（类似于俄罗斯套娃，必须一层一层套好，不能交叉）。

    正确写法：

    <ul>
  <li>列表项一</li>
  <li>列表项二</li>
</ul>

    错误写法（交叉嵌套）：

    <ul>
  <li>列表项一
    <p>这是一个段落？       <!-- 错误：li还没关闭，就打开了p -->
  </li>
  </p>                     <!-- 这里想关闭p，但已经乱套了 -->
</ul>

    嵌套对了，页面才能正常渲染；嵌套错了，浏览器可能会“猜”你的意图，但容易导致显示错乱。

  7. 大小写敏感性

    HTML标签和属性名不区分大小写，<P> 和 <p> 是一样的。但为了代码规范、易读，业界普遍使用小写。

    属性值（比如链接地址、文字内容）是区分大小写的，特别是URL和文件名。

    <A HREF="Page.HTML">链接</A>   <!-- 技术上可以，但不推荐 -->
<a href="page.html">链接</a>   <!-- 推荐：全小写，清晰统一 -->

  8. 空白与换行

    在HTML中，多个连续的空格、制表符、换行符在浏览器中通常只会被渲染成一个空格。这被称为“空白折叠”。

    例如下面这段代码，虽然换行了，但显示出来是连在一起的文字：

    <p>这是
  一段     文字。</p>

    实际显示效果为：这是一段 文字。（多个空格合并成一个）

    如果你想保留原格式，可以用 <pre> 标签，或者使用CSS的 white-space 属性。

  9. 块级元素 vs 内联元素（简单了解）

    虽然这不是语法本身，但对理解如何布局很有帮助。

    • 块级元素：默认独占一行，像段落 <p>、标题 <h1>、<div> 等。
    • 内联元素：不会换行，像加粗 <strong>、链接 <a>、图片 <img> 等。

    了解它们有助于你正确地嵌套元素（例如，内联元素通常放在块级元素内部，反之则可能不合规范）。

2.3. HTML 文档结构

我们把下面的代码放入index.html，它便是整个页面文件：

<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <title>页面标题</title>
    </head>
    <body>
        <h1>欢迎访问我的网站</h1>
        <p>这是一个段落。</p>
        <button id="myButton">点击我</button>
    </body>
</html>

在这里，我们有以下内容：

  • <!DOCTYPE html> — 声明为 HTML5 文档，这是必需的。它们并没有做太多事情，只是确保你的文档正常运行。
  • <html></html> — <html> 元素。该元素包含整个页面上的所有内容，有时称为根元素。它还可以包括 lang 属性，设置文档的主要语言。
  • <head></head> — <head> 元素。在该元素中的内容不会在浏览器中显示。它里面包含的信息反应了一些该文档的一些信息，比如 keywords 和你希望出现在搜索结果中的页面描述、设置内容样式的 CSS、字符集声明等。
  • <meta charset="utf-8"> — 此元素将文档应使用的字符集设置为 UTF-8，该字符集包括了全球绝大多数书面语言的大多数字符。从本质上讲，它现在可以处理你可能放置在其上的任何文本内容。没有理由不设置这个，它可以帮助避免以后出现一些问题。需要注意的是，该网页文件在保存的时候，也要保存为 "utf-8"编码的文件。
  • <meta name="viewport" content="width=device-width"> — 此元素 确保页面以视口宽度呈现，主要是为了防止移动设备中的浏览器呈现比视口更宽的页面，然后将其缩小。
  • <title></title> — <title> 元素。这将设置页面的标题，即显示在加载页面的浏览器选项卡中的标题。当你添加书签/收藏该页面时，它也用于描述该页面。
  • <body></body> — <body> 元素。其中包含你希望在网络用户访问你的页面时向其显示的所有内容，无论是文本、图片、视频、游戏、可播放的音轨还是其他内容。

3. 文档结构

3.1. 文档的基本部分

网页可以而且将会看起来彼此相当不同，但它们都倾向于共享相似的标准组件，除非页面正在显示全屏视频或游戏，或是某种艺术项目的一部分，或者只是结构很糟糕：

  • 标头：
    通常是顶部有一个大条带，带有大标题、徽标，也许还有标语。从一个网页到另一个网页，这一点通常保持不变。

  • 导航栏：
    指向网站主要部分的链接；通常由菜单按钮、链接或选项卡表示。与标题一样，此内容通常从一个网页到另一个网页保持一致 - 网站上不一致的导航只会导致用户感到困惑和沮丧。许多网页设计师认为导航栏是标题的一部分而不是单独的组件，但这不是必需的；事实上，有些人还认为将这两个功能分开对 accessibility 来说更好，因为如果这两个功能分开，屏幕阅读器可以更好地阅读它们。

  • 主要内容：
    中心的一个大区域，包含给定网页的大部分独特内容，例如你想要观看的视频，或者你正在阅读的主要故事，或者你想要查看的地图，或者新闻标题， 等等。这是网站的一部分，每一页肯定会有所不同！

  • 侧边栏：
    一些外围信息、链接、引用、广告等。通常，这与主要内容中包含的内容相关（例如在新闻文章页面上，侧边栏可能包含作者的简介或相关文章的链接），但也有 在某些情况下，你还会发现一些重复出现的元素，例如辅助导航系统。

  • 页脚：
    页面底部的一条条带，通常包含精美印刷、版权声明或联系信息。这是放置常用信息（如标题）的地方，但通常该信息对于网站本身来说并不重要或次要。页脚有时也用于 SEO (Search Engine Optimization)目的，提供快速访问流行内容的链接。

3.2. 构建文档的语义标签

在 HTML 代码中，可以根据内容的功能（如前）来标记内容部分 - 你可以使用明确表示上述内容部分的元素，屏幕阅读器等辅助技术可以识别这些元素并帮助完成 "找到主导航" 或 "找到主要内容。" 等任务。

为了实现此类语义标记，HTML 提供了专用标签，你可以使用它们来表示此类部分，例如：

  • 标头：<header>。
  • 导航栏：<nav>。
  • 主要内容：<main>，具有由 <article>、<section> 和 <div> 元素表示的各种内容小节。
  • 侧边栏：<aside>；通常放置在 <main> 内。
  • 页脚：<footer>。

3.2.1. 这些标签的语义信息：

  • <main> 用于该页面特有的内容。每页仅使用 <main> 一次，并将其直接放在 <body> 内。理想情况下，它不应嵌套在其他元素中。
  • <article> 包含一个相关内容块，这些内容本身就有意义，无需页面的其余部分（例如，单个博客文章）。
  • <section> 与 <article> 类似，但它更多的是用于将页面的单个部分组合在一起，构成一个功能（例如，迷你地图或一组文章标题和摘要）或主题。每个部分以 heading 开始被认为是最佳实践；另请注意，你可以根据上下文将 <article> 分解为不同的 <section>，或将 <section> 分解为不同的 <article>。
  • <aside> 包含与主要内容不直接相关的内容，但可以提供与其间接相关的附加信息（术语表条目、作者传记、相关链接等）。
  • <header> 代表一组介绍性内容。如果它是 <body> 的子级，则它定义网页的全局标头，但如果它是 <article> 或 <section> 的子级，则它定义该部分的特定标头（尽量不要将其与 标题和标题 混淆）。
  • <nav> 包含页面的主要导航功能。辅助链接等不会出现在导航中。
  • <footer> 代表页面的一组最终内容。

3.2.2. 非语义封装器

有时你会遇到这样的情况：找不到理想的语义元素来将某些项目组合在一起或封装某些内容。有时你可能只想将一组元素组合在一起，以将它们作为具有某些 CSS 或 JavaScript 的单个实体来影响。对于此类情况，HTML 提供了 <div> 和 <span> 元素。你最好将它们与合适的 class 属性一起使用，为它们提供某种标签，以便轻松定位它们。

  • <span> 是一个内联（inline）非语义元素，只有当你想不出更好的语义文本元素来封装你的内容，或者不想添加任何特定含义时，才应该使用它。例如：
<p>
  The King walked drunkenly back to his room at 01:00, the beer doing nothing to
  aid him as he staggered through the door.
  <span class="editor-note">
    [Editor's note: At this point in the play, the lights should be down low].
  </span>
</p>

在这种情况下，编者注应该只是为该剧的导演提供额外的指导；它不应该具有额外的语义含义。对于视力正常的用户来说，CSS 或许可以用来稍微拉开注释与正文的距离。

  • <div> 是一个块级非语义元素，只有在你想不出更好的语义块元素来使用，或者不想添加任何特定含义时才应该使用它。例如，想象一下你可以在访问电子商务网站期间随时选择拉出的购物车小部件：
<div class="shopping-cart">
  <h2>Shopping cart</h2>
  <ul>
    <li>
      <p>
        <a href=""><strong>Silver earrings</strong></a>: $99.95.
      </p>
      <img src="../products/3333-0985/thumb.png" alt="Silver earrings" />
    </li>
    <li>…</li>
  </ul>
  <p>Total cost: $237.89</p>
</div>

这不是一个<aside>，因为它不必然与当前页面的主要内容相关（你希望它从任何地方都能看到）。它甚至不太应该使用<section>，因为这不是页面主要内容的一部分。在这种情况下，使用<div>足够了。我们还添加了一个标题作为标志，以便屏幕阅读器用户能够更容易地找到它。

警告：Div 使用起来非常方便，因此很容易过度使用它们。由于它们没有语义价值，因此只会让你的 HTML 代码变得混乱。仅当没有更好的语义解决方案时才小心使用它们，并尝试将它们的使用减少到最低限度，否则你将很难更新和维护文档。

3.2.3. 换行符和水平线

你偶尔会使用并且需要了解的两个元素是 <br> 和 <hr>。

  • <br>:在段落中创建换行符；当你需要一系列固定的短行（例如在邮政地址或一首诗中）时，这是强制采用刚性结构的唯一方法。例如：
<p>
  There once was a man named O'Dell<br />
  Who loved to write HTML<br />
  But his structure was bad, his semantics were sad<br />
  and his markup didn't read very well.
</p>

如果没有 <br> 元素，该段落将仅呈现为一长行；代码中包含 <br> 元素时，如下：

There once was a man named O'Dell
Who loved to write HTML
But his structure was bad, his semantics were sad
and his markup didn't read very well.

  • <hr>:<hr> 元素在文档中创建一条水平线。从视觉上看，它看起来就像一条水平线。举个例子：
<p>
  Ron was backed into a corner by the marauding netherbeasts. Scared, but
  determined to protect his friends, he raised his wand and prepared to do
  battle, hoping that his distress call had made it through.
</p>
<hr />
<p>
  Meanwhile, Harry was sitting at home, staring at his royalty statement and
  pondering when the next spin off series would come out, when an enchanted
  distress letter flew through his window and landed in his lap. He read it
  hazily and sighed; "better get back to work then", he mused.
</p>

效果如下：

Ron was backed into a corner by the marauding netherbeasts. Scared, but determined to protect his friends, he raised his wand and prepared to do battle, hoping that his distress call had made it through.

Meanwhile, Harry was sitting at home, staring at his royalty statement and pondering when the next spin off series would come out, when an enchanted distress letter flew through his window and landed in his lap. He read it hazily and sighed; "better get back to work then", he mused.

4. HTML标签简表

在HTML5中，有超过100个标签可供使用。为了帮你系统地掌握它们，我将这些标签按照功能分门别类地整理成了下面的表格。这份整理主要参考了权威的W3Schools的HTML参考手册，并补充了HTML5中新引入的标签。

4.1. 📜 基础文档结构

这些标签构成了一个HTML页面的骨架。

标签 功能描述
<!DOCTYPE> 定义文档类型，告诉浏览器使用哪种HTML规范来解析页面，必须写在第一行。
<html> 定义整个HTML文档的根元素。
<head> 定义文档的头部，是所有元数据（如标题、样式、字符集）的容器。
<title> 定义文档的标题，会显示在浏览器的标题栏或标签页上。
<body> 定义文档的主体部分，包含所有在浏览器窗口中可见的内容。

4.2. 🏷️ 内容分组与语义化

这类标签用于组织和划分页面内容，使其结构清晰且富有意义。其中很多是HTML5新增的语义化标签。

标签 功能描述
<h1> 到 <h6> 定义六级标题，<h1> 级别最高（最重要），<h6> 级别最低。
<p> 定义一个段落。
<br> 插入一个简单的换行符。
<hr> 定义内容主题的分割线（水平线）。
<div> 定义一个块级分区或节，常用作页面布局的容器。
<span> 定义一个行内容器，用于对文本进行分组和样式化。
<header> 定义文档或节的页眉，通常包含一组介绍或导航链接。
<footer> 定义文档或节的页脚，通常包含版权信息、作者信息等。
<main> 定义文档的主要内容区域，一个页面只有一个。
<section> 定义文档中的一个独立节，通常带有主题或标题。
<article> 定义独立的、可复用的内容块，如博客文章、新闻报道。
<aside> 定义与周围内容相关的辅助信息，如侧边栏、广告。
<nav> 定义一组导航链接。
<address> 定义文档或文章的作者/所有者的联系信息。
<figure> 定义自包含的内容流，如图像、图表、代码，通常带有标题。
<figcaption> 定义 <figure> 元素的标题。
<details> 定义用户可见或隐藏的额外细节，常与 <summary> 配合使用。
<summary> 为 <details> 元素定义可见的标题或摘要。
<dialog> 定义一个对话框或窗口。
<menu> 定义命令列表或菜单。

4.3. ✍️ 文本格式化

用于标记和格式化文本内容。

标签 功能描述
<strong> 定义重要的文本，通常以粗体显示。
<em> 定义强调的文本，通常以斜体显示。
<b> 定义粗体文本，用于吸引注意力但不表示特别重要。
<i> 定义斜体文本，用于表示技术术语、外语短语等。
<mark> 定义需要标记或高亮的文本。
<small> 定义旁注或小字，如免责声明、版权声明。
<del> 定义文档中已删除的文本。
<ins> 定义文档中新插入的文本。
<sub> 定义下标文本。
<sup> 定义上标文本。
<abbr> 定义缩写或首字母缩略语。
<cite> 定义作品的标题（如书、歌曲、画作）。
<blockquote> 定义从其他来源引用的长块内容。
<q> 定义短的行内引用。
<code> 定义一段计算机代码。
<pre> 定义预格式化的文本，保留空格和换行。
<time> 定义日期或时间。
<meter> 定义已知范围内的度量值（如磁盘使用量）。
<progress> 定义任务的进度（进度条）。

4.4. 🔗 链接与资源

用于创建超链接和引入外部资源。

标签 功能描述
<a> 定义一个超链接，用于链接到另一个页面或资源。
<link> 定义当前文档与外部资源（如样式表）的关系。
<base> 定义页面中所有相对 URL 的基准 URL。

4.5. 🖼️ 图像与多媒体

用于在网页中嵌入图像、音频和视频等媒体内容。

标签 功能描述
<img> 定义图像。
<picture> 定义包含多个 <source> 元素的容器，用于实现响应式图像。
<map> 定义图像映射（可点击的链接区域）。
<area> 定义图像映射内部的区域。
<audio> 定义声音内容（如音乐或音频流）。
<video> 定义视频或电影。
<source> 为 <audio>、<video> 或 <picture> 元素定义多个媒体资源。
<track> 为 <audio> 或 <video> 元素定义文本轨道（如字幕）。
<canvas> 通过脚本（如 JavaScript）在网页上绘制图形。
<svg> 定义一个 SVG 图形容器。
<iframe> 定义内联框架，用于在当前页面内嵌入另一个 HTML 文档。
<embed> 定义外部交互内容或插件的容器。
<object> 定义嵌入的对象（如 applet、插件）。
<param> 为 <object> 元素定义参数。

4.6. 📋 列表

用于创建各种类型的列表。

标签 功能描述
<ul> 定义无序列表。
<ol> 定义有序列表。
<li> 定义列表中的项目。
<dl> 定义描述列表（键值对列表）。
<dt> 定义描述列表中的一个术语/名字。
<dd> 定义描述列表中对术语/名字的描述。

4.7. 📊 表格

用于创建和格式化表格数据。

标签 功能描述
<table> 定义表格。
<caption> 定义表格的标题。
<tr> 定义表格中的行。
<th> 定义表格中的表头单元格。
<td> 定义表格中的标准单元格。
<thead> 定义表格的头部区域。
<tbody> 定义表格的主体区域。
<tfoot> 定义表格的脚注区域。
<col> 定义表格中一列的属性，用于为列设置样式。
<colgroup> 定义表格中一个或多个列的分组，用于格式化。

4.8. 📝 表单与用户输入

用于创建交互式表单，以收集用户输入。

标签 功能描述
<form> 定义用户输入的 HTML 表单。
<input> 定义输入控件，类型多样（文本、密码、复选框等）。
<textarea> 定义多行的文本输入控件。
<button> 定义可点击的按钮。
<select> 定义下拉列表。
<optgroup> 定义下拉列表中相关选项的分组。
<option> 定义下拉列表中的一个选项。
<label> 为 <input> 元素定义标签（标注）。
<fieldset> 将表单中相关元素组合成一组。
<legend> 为 <fieldset> 元素定义标题。
<datalist> 定义输入控件的预定义选项列表（与 input 的 list 属性配合）。
<output> 定义计算结果，用于显示脚本计算出的输出。

4.9. ⚙️ 元数据与脚本

包含关于文档的信息以及用于增强交互性的脚本。

标签 功能描述
<meta> 定义关于 HTML 文档的元数据，如字符集、描述、关键词。
<style> 定义文档的 CSS 样式信息。
<script> 定义客户端脚本，如 JavaScript。
<noscript> 定义当浏览器不支持或不启用客户端脚本时显示的替代内容。
<template> 定义在页面加载时隐藏的 HTML 片段，可通过脚本克隆后插入到文档中。

4.10. 💬 其他标签

一些不便于归类的标签。

标签 功能描述
<!--...--> 定义 HTML 注释，浏览器不会显示注释内容。
<ruby>, <rt>, <rp> 定义东亚文字的注音或字符注解（ruby 注释）。
<bdi> 定义一块可能以不同方向格式化的文本，使其脱离周围文本的方向设置。
<bdo> 覆盖当前文本的方向。
<wbr> 定义可能的换行位置，告诉浏览器在此处可以换行。

4.11. ⚠️ HTML中已移除的标签

一些旧标签在HTML5中已被废弃，不应再使用。它们的功能通常由CSS或其他新标签替代。

标签 替代方案
<acronym> 使用 <abbr>。
<applet> 使用 <embed> 或 <object>。
<basefont> 使用 CSS 的 font 属性。
<big> 使用 CSS 的 font-size 属性。
<center> 使用 CSS 的 text-align 属性。
<dir> 使用 <ul>。
<font> 使用 CSS 的字体相关属性。
<frame>, <frameset>, <noframes> 不再支持，改用 <iframe> 或服务器端技术。
<strike> 使用 <del>、<s> 或 CSS 的 text-decoration。
<tt> 使用 CSS 的 font-family 属性。

掌握了这些标签的分类和功能，你对HTML5的理解会更上一层楼。如果想深入了解某个类别或特定标签的用法，随时可以问我。

<meta> 设置网页元信息（如字符集、描述、关键词）。
<style> 内嵌CSS样式。
<script> 引入或编写JavaScript代码。

5.10. 💬 注释

标签 描述
<!-- ... --> HTML注释，浏览器不显示。

以上标签覆盖了绝大多数日常网页开发所需的基础元素。掌握它们，你就可以搭建出结构清晰、功能完整的静态网页了。需要示例或进一步解释吗？

6. HTML字符实体

在HTML中，像 <、>、& 这类字符已经被语言本身用作标签或转义的标识，所以不能直接在文本中使用。当我们想在网页上显示这些符号时，就必须使用 HTML字符实体 来代替 。

HTML5 处理程序必须支持下表中列出的 5 个特殊字符 。

你可以在文本中混合使用 实体名称（如 &copy;）和 实体编号（如 &#169;）。实体名称更好记，但实体编号的兼容性通常更广 。

6.7. 💡 实际使用示例

假设你想在网页上显示一行文本：HTML <head> 标签，如果你直接写，浏览器会把它误认为是标签的开始。正确的写法是使用字符实体：

代码：

<p>HTML &lt;head&gt; 标签</p>
<p>版权所有 &copy; 2024</p>
<p>价格：10 &pound; 约合 12 &euro;</p>

浏览器显示效果：

  • HTML <head> 标签
  • 版权所有 © 2024
  • 价格：10 £ 约合 12 €

掌握这些常用的字符实体，能让你在处理特殊符号时更加得心应手。如果你想了解某个特定类别的符号（比如希腊字母或数学运算符），随时可以再问我。

7. 常用属性

以下是HTML中最常用、最基础的属性，按功能分类整理，方便初学者系统掌握。每个属性都附有简要描述和适用场景说明。

7.1. 🌐 全局属性（适用于所有HTML元素）

这些属性可以在任何HTML标签中使用。

属性 描述 常用示例
class 为元素定义一个或多个类名，用于CSS样式或JavaScript选择。 <p class="important note">...</p>
id 定义元素的唯一标识符，在同一页面中必须唯一。 <div id="header">...</div>
style 为元素添加内联CSS样式。 <span style="color: red;">文本</span>
title 提供额外提示信息，鼠标悬停时显示为工具条。 <abbr title="HyperText Markup Language">HTML</abbr>
lang 指定元素内容的语言。 <html lang="zh-CN">
data-* 自定义数据属性，用于存储页面或应用的私有数据。 <div data-user-id="123">...</div>
hidden 隐藏元素（布尔属性）。 <p hidden>这段文字会被隐藏</p>
tabindex 控制元素的Tab键导航顺序。 <input tabindex="1">
accesskey 定义激活元素的快捷键。 <a href="index.html" accesskey="h">首页</a>

7.2. 📝 表单元素属性

用于 <form> 及其内部控件（如 <input>、<textarea>、<select> 等）。

属性 描述 适用标签
type 指定输入框的类型（文本、密码、邮箱、提交按钮等）。 <input>
name 定义表单元素的名称，用于提交数据时的键名。 <input>、<textarea>、<select>
value 定义元素的初始值。 <input>、<textarea>、<option>
placeholder 在输入框中显示提示文本，输入时消失。 <input>、<textarea>
required 表示该字段必须填写（布尔属性）。 <input>、<textarea>、<select>
disabled 禁用元素，使其不可交互（布尔属性）。 <input>、<textarea>、<button>、<select>
readonly 设置字段为只读，不能修改但可以提交。 <input>、<textarea>
checked 预选单选框或复选框（布尔属性）。 <input type="radio">、<input type="checkbox">
selected 预选下拉列表中的某个选项（布尔属性）。 <option>
multiple 允许在 <select> 中多选，或允许上传多个文件。 <select>、<input type="file">
maxlength 限制输入的最大字符数。 <input>、<textarea>
min / max 规定数字或日期输入的最小/最大值。 <input type="number">、<input type="date">
step 指定数字输入的步进间隔。 <input type="number">
pattern 用正则表达式验证输入值。 <input type="text">
autocomplete 开启或关闭自动完成功能（on/off）。 <form>、<input>
novalidate 提交表单时不进行验证。 <form>
enctype 规定表单数据的编码方式（用于文件上传）。 <form>

7.3. 🔗 链接与资源属性

用于 <a>、<link>、<img>、<script> 等标签。

属性 描述 适用标签
href 指定链接目标的URL。 <a>、<link>、<base>
src 指定外部资源的URL（如图片、脚本、iframe）。 <img>、<script>、<iframe>、<audio>、<video>
alt 图像的替代文本，当图像无法显示时显示。 <img>
target 指定在何处打开链接（_self、_blank、_parent、_top）。 <a>、<form>
rel 定义当前文档与链接资源的关系（如 stylesheet、nofollow）。 <a>、<link>
download 指示浏览器下载链接的资源，而不是导航到它。 <a>
media 指定链接资源适用的媒体类型（如 print、screen）。 <link>
type 指定链接资源的MIME类型（如 text/css、image/png）。 <link>、<a>、<script>
charset 定义外部脚本的字符编码。 <script>
async / defer 控制脚本的加载和执行方式。 <script>

7.4. 🖼️ 图像与多媒体属性

用于 <img>、<audio>、<video>、<source> 等。

属性 描述 适用标签
src 媒体文件的URL。 <img>、<audio>、<video>、<source>
alt 图像的替代文本。 <img>
width / height 指定媒体元素的宽度和高度（像素或百分比）。 <img>、<video>、<canvas>、<iframe>
controls 显示播放控件（如播放、暂停按钮）。 <audio>、<video>
autoplay 自动开始播放（布尔属性）。 <audio>、<video>
loop 循环播放（布尔属性）。 <audio>、<video>
muted 默认静音（布尔属性）。 <audio>、<video>
poster 指定视频加载前显示的预览图像。 <video>
preload 指示如何预加载媒体（none、metadata、auto）。 <audio>、<video>
srcset 响应式图像：不同屏幕尺寸使用的不同图像源。 <img>、<picture>
sizes 与 srcset 配合，定义图像显示大小。 <img>、<picture>

7.5. 📊 表格属性

用于 <table> 及其子元素。

属性 描述 适用标签
colspan 单元格占据的列数。 <td>、<th>
rowspan 单元格占据的行数。 <td>、<th>
border 表格边框宽度（建议用CSS代替）。 <table>
cellpadding / cellspacing 单元格内边距/间距（建议用CSS代替）。 <table>
summary 表格内容的摘要（为辅助技术提供）。 <table>
scope 定义表头单元格关联的行/列（row/col）。 <th>

7.6. ⚙️ 事件属性（用于交互）

这些属性直接在标签中绑定JavaScript代码（但现代开发更推荐用 addEventListener 分离）。

类别 常用事件属性
鼠标事件 onclick、ondblclick、onmouseover、onmouseout、onmousedown、onmouseup、onmousemove
键盘事件 onkeydown、onkeypress、onkeyup
表单事件 onsubmit、onreset、onfocus、onblur、onchange、oninput
页面/窗口事件 onload、onunload、onresize、onscroll
触摸/移动事件 ontouchstart、ontouchmove、ontouchend
拖拽事件 ondrag、ondrop、ondragover、ondragstart

示例：<button onclick="alert('点击了')">点我</button>

7.7. 🧩 元数据与文档属性

用于 <meta>、<html>、<body> 等。

属性 描述 适用标签
charset 指定文档的字符编码。 <meta>
name 定义元数据的名称（如 keywords、description、viewport）。 <meta>
content 与 name 或 http-equiv 配合，提供元数据值。 <meta>
http-equiv 模拟HTTP响应头（如 refresh、content-type）。 <meta>
manifest 指定离线应用缓存清单（已废弃）。 <html>

7.8. 📦 列表属性

用于 <ol>、<ul>、<li> 等。

属性 描述 适用标签
type 设置列表标记类型（1、A、a、I、i 或 disc、square、circle）。 <ol>、<ul>、<li>
start 有序列表的起始数字。 <ol>
reversed 降序排列有序列表（布尔属性）。 <ol>
value 指定列表项的当前序号。 <li>

7.9. 📐 其他常用属性

属性 描述 适用标签
cite 指定引用来源的URL。 <blockquote>、<q>、<del>、<ins>
datetime 指定与 <time> 关联的机器可读日期/时间。 <time>
accept 指定文件上传允许的MIME类型。 <input type="file">
dirname 提交表单时发送文本方向信息。 <input>、<textarea>
form 将元素与页面上的某个表单关联（即使不在表单内）。 <input>、<textarea>、<button>、<select>
formaction / formenctype 等 覆盖表单的 action、enctype 等属性（用于提交按钮）。 <button>、<input type="submit/image">
ismap / usemap 将图像定义为服务器端/客户端图像映射。 <img>

掌握这些常用属性后，你就可以更灵活地控制HTML元素的行为和外观。如果想了解某个属性的具体用法或更多示例，欢迎随时提问！
