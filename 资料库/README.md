## 目录结构

```
资料库/
  00_模板/              模板文件（知识点模板、TeX模板等）
  01_收件箱/            待处理入口
  02_学校库/            按 学校 → 学院 → 阶段 → 学期 → 课程 组织
    01_河南大学/
      01_软件学院/
        01_大一/
          02_下学期/    高等数学A（二）、离散数学、面向对象程序设计Java、Web编程基础、大学物理、电工电子技术基础、思想道德与法治
        02_大二/
          02_下学期/    数据库系统、计算机网络、计算机组成原理、软件工程、移动开发
  90_公共资料/          跨课程通用资料
  99_全局归档/          历史归档
```

## 使用方式

1. 用 `libraryctl` 管理目录结构：`node scripts/libraryctl/libraryctl.mjs --help`
2. 每门课的 `course.yaml` 记录元信息，`materials.csv` 记录资料索引
3. 原始资料放在 `04_原始资料/` 对应子目录
4. 知识点放在 `02_知识点库/`
5. 成品复习包放在 `01_发布区/01_成品复习包/`
